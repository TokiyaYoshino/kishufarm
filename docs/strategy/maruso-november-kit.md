週4本 × 4週＝16本。柱の比率は A現場7・B食べ方5・C知識3・D人1。
**各本の作り方**：冒頭1秒で「何が起きるか」を見せる → 縦9:16 → 15〜30秒 → 必ず声を入れる → 撮って出し8割。

**2つとも作って同じ動画を流す。** まっちさんの数字はInstagram 6.9万／TikTok 5.98万でほぼ互角なので、どちらが有利かの議論に時間を使わない。

### ゼロ期だけの修正
- **コメント返信の毎日10分 → 他の農家アカウントへのコメント・リプライに使う。** ゼロの時期は自分にコメントが来ない。最初の露出はここから来る。フォロワーが付き始めたら自分への返信に切り替える
- **最初の30日はフォロワーがほぼ増えない前提。** 1本目でバズを狙うと続かない。16本を出し切ることだけを目標にする
- 機材はスマホのみ。編集アプリは1つに絞る
- **風の日は声が消える。** スマホを口元に近づけるか、ナレーションを後で乗せる

# 第2部：代行型の営業キット

## 流れ（11月の4週）

| 週 | やること |
|---|---|
| 1週 | 商圏の確認（片道何分圏）／仕入先候補20件・売り先候補20件のリスト化 |
| 2週 | 売り先に10件あたる（飛び込みより電話→訪問）。仕入先に3件あたる |
| 3週 | 1農家 × 1売り先で**最小ループを1回通す**（受注→集荷→納品→請求） |
| 4週 | 精算して条件を見直す。産直モールにも出品して反応を見る |

## 売り先（飲食店・小売）への聞き方

**先に3つ聞く。提案は後。**
1. 今の仕入れで**困っていることは何か**（量・規格・値段・届く曜日のどれか）
2. 玉ねぎは**週にどれくらい使うか**（kg／箱数）
3. **誰から**仕入れているか（業者／市場／直）

**提案はこの形。** 卸では付加価値が認められにくいという構造が出発点なので、こちらが引き受けるのは「量と手間」、こちらが持つのは「値決め」。
- **週次の定期納品**（曜日を固定する）
- **規格の融通**（大きさがそろわない分、小玉・大玉も使い道に合わせて出す）
- **その代わり価格はこちらが決める**

**サンプルは必ず置いて帰る。** 試して味の差が出ない相手は、価格競争になるので追わない。

## 仕入先（近隣農家）への切り出し

**相手の困りごとはほぼ共通して「売り先がない」「ネットが分からない」「出荷規格に通らない分が捨てになる」。** まっちさんの代行事業も、ここを引き受ける形で成立している。

言うこと：
- **売り先はこちらで持つ**（飲食店・通販）
- **規格外も含めて売る**
- **販売・梱包・発送・集金はこちらでやる**
- **手数料は販売額の○%**（＝下記で決める）

## 手数料の決め方

**相場をそのまま当てない。** 自分のコストから逆算する。

販売額 −（送料 ＋ 梱包資材 ＋ 決済手数料 ＋ 集荷の移動コスト ＋ 自分の作業時間）＝ 残り
→ この残りが**自分の手間に見合う**なら成立。見合わないなら手数料率ではなく**最小ロット**を上げる。

**確認すること**：産直モール（食べチョク等）の販売手数料と送料設定。**モールに出す場合はその手数料が上限の目安になる**ので、自分の代行手数料はそれより低く置けるかで競争力が決まる。

## 合意メモに書く8項目

口約束で始めると、ロスが出た時と値段を下げた時に必ず揉める。A4一枚で足りる。

- [ ] **品目と期間**（何を、いつからいつまで）
- [ ] **数量**（週あたりの目安と、最小・最大）
- [ ] **価格の決定権**（こちらが決める、と明記）
- [ ] **手数料**（率または固定額、計算の基準になる金額）
- [ ] **精算日**（販売月の翌月○日など）
- [ ] **ロスの負担**（売れ残り・傷みは誰が負うか。**代行型なら農家側**。ここを曖昧にしない）
- [ ] **表示の責任**（産地・名称の表示は誰が行うか。生鮮食品は名称と原産地が義務）
- [ ] **やめ方**（何日前に言えば終われるか）

## 始める前の確認（法務）

- **食品表示**：生鮮食品は**名称と原産地の表示が義務**。業者間取引も対象。複数産地を混ぜるなら重量の多い順に全産地。袋詰めして売る形にするなら事業者名・住所の表示が関わるため**保健所・農政事務所に確認**
- **インボイス**：代行型（受託手数料）なら論点は小さい。**買取型に移る時点で**国税庁の公式資料で控除率を確認（2026年10月1日が転換点で、解説間で「80%→70%」と「80%→50%」の食い違いがある）
- **営業許可**：生鮮をそのまま売る限り不要。**カット・加工・瓶詰めをした時点で食品衛生法の許可が必要**
