# 霧珠ファーム 売上目標（作物・会員権・Web支援・SNS運用）

2026-10-17 作成。`TokiyaYoshino/20260407` の `operating-rules.md` の目標「2028年10月までに個人の年収1000万円（月83万円）」から逆算する。

## 前提

- **年度は11月〜10月で数える。** 2026年11月のぶどう植え付けに合わせ、最後の年度（2027/11〜2028/10）が目標の期限で終わるようにする
  - 2027年度 = 2026/11〜2027/10（中間）
  - 2028年度 = 2027/11〜2028/10（**年収1000万円の年**）
- 「年収」は売上から直接の経費を引いた残り（税引前）で数える
- **美容室の売上は入れない。** 個人で別にやる（2026-10-17 決定）。美容室のSNS運用は、下の「SNS運用代行」と同じ扱いで数える
- **自社（霧珠ファーム）のSNSは売上に数えない。** 会員権と作物を売るための道具として扱う
- **Web支援の単価は値上げ案（1件あたり平均56万円）で置く。** 計画書 第4章の案。TODO B1 の決定はこの表をもって値上げ案とする（違えば下の「決めること」で戻す）
- 作物の面積・単価は**仮置き**（一般的な目安）。実際の数字が分かったら差し替える

### 各項目の置き方

**ぶどうの木会員権**
- 2027年5月に初回10口（3万×6・5万×3・10万×1 = 43万円）。2028年4月に第2回で100口まで（初回10口の更新を含む）。木の上限100本と同じ
- 経費15%は名前プレート・月1回のレポート・季節便の送料・体験の当日費用
- 段階ごとの特典（案）

| | 3万円 | 5万円 | 10万円 |
|---|---|---|---|
| 名前入りプレート・月1回の成長レポート・木の名前の投票 | ○ | ○ | ○ |
| 収穫祭の招待 | ○ | ○ | ○ |
| 畑での作業体験（剪定か収穫） 年1回 | | ○ | ○ |
| 霧珠の野菜の季節便（たまねぎ・万願寺） | | 年1回 | 年2回 |
| 初ワインの優先購入権 | | | ○ |

- 特典の中身は 10/11 の SNS×LINE会員計画（`docs/kirishu-farm/01-sns-membership-plan.md`）の基本形に、段階の差を足したもの
- **ワインそのものを特典で送るのは入れない。** 初ワインは4〜5年後で、酒類の免許も別に要る。約束できるのは「優先して買える権利」まで
- 野菜の季節便を特典に入れるのは、作物の直販先を増やすため

**Web支援**
- 2027年度は年4件（約3か月に1件）、2028年度は年8件（約1.5か月に1件）
- 8件は、計画書 第7章の「値上げ・外注あり（1件43時間）」の前提でないと回らない
- 保守は納品済み2社＋新規の一部が月1.5万円で契約する置き方

**SNS運用代行**
- **最初は無料で運用し、成果が出たら月3万円の有料に切り替える**（2026-10-17 決定）
- 2027年度は、2社が半年目から有料になる置き方（2社 × 3万 × 6か月 = 36万円）
- 2028年度は6社が通年で有料
- 「成果が出た」の基準は、無料で始める前に相手と決めておく（例：3か月で問い合わせ・予約が何件増えたら有料にする）。基準がないと無料のまま続く

**作物**（農業スキルの一般的な目安。地域・年で大きく変わる）
- たまねぎ：10aあたり4〜5t。JA出荷は100〜150円/kg、直販は300〜500円/kg。秋植えで5〜6月収穫
- 万願寺とうがらし：10aあたり2〜3t。市場出荷は500〜800円/kg、直販は1,000〜1,500円/kg。6〜10月に収穫が続く
- 経費率が高い（種苗・肥料・資材・出荷資材・手数料）ので、粗利率は45〜50%で置いた

## この表から分かること

1. **作物は粗利の約14%。** 主な役割は売上よりも、SNSの発信の材料と、会員権の特典（季節便）になる
2. **一番大きいのは会員権の第2回募集（2028年4月）。** 粗利の36%がこの1回にかかっている。2027年3月の時点でインスタとLINEの数が計画の半分に届いていなければ、口数か単価を決め直す（会員計画のタスク 2-5）
3. **SNS運用代行は無料期間の出口が肝。** 6社を有料にするには、無料で始めた相手のほとんどを有料に切り替える必要がある
4. **8〜9月は手が足りなくなる。** ぶどうの収穫と万願寺の最盛期が重なる。この2か月はWeb制作を受けない
