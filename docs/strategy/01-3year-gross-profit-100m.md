## 1. 結論 — 何をやるか

### 事業案:「接骨院・整骨院専門、広告に頼らない集客の月額サービス」

> **広告を打てない接骨院のために、サイト・Googleマップ・AI検索・LINE予約・口コミを
> 一式で用意し、毎月運用する。月額 3.98万円〜。**

いまの Web 受託を**「作って納品する仕事」から「毎月払ってもらう仕組み」に作り替え**、
売り先を**接骨院・整骨院の1業種に絞る**。新しいことを始めるのではなく、
すでに持っている技術・実績・調査を一番効くところに集めるという判断です。

### なぜ接骨院か — 今この業種にだけ「買う理由」がある

1. **広告が使えない。** 2025年2月のあはき・柔整広告ガイドラインで、リスティング広告やバナー広告は規制の対象になった。
   一方でサイト本体は原則として広告に当たらない。**有料の集客手段がないので、サイト・Googleマップ・AI検索で見つけてもらうしかない**
2. **保険収入が減っていく。** 2026年の療養費改定（改定率+0.6%で実質マイナス、長期・多部位の償還払い化）で、
   **自費メニューに移らざるを得ない**。でも自費の患者は、自分で集めないと来ない
3. **市場が大きく、競争相手が少ない。** 全国50,364施術所。250院でも**シェア0.5%**。
   大手は広告運用を売ってきたので、規制後に売れるものが手元にない
4. **作るものは今と同じ。** ANUHAIR（整体併設）で作った LINE 予約・EC・AEO・口コミ自動化がそのまま使える
5. **規制がそのまま強みになる。** ガイドラインのチェックを、制作と運用の全工程に組み込んでおく。
   規制を知らない制作会社は売れない、規制を怖がる院は自分では運用できない。その間に入れる

> ⚠ 療養費改定とガイドラインの中身は二次情報です（TODO E2）。**営業トークの根拠なので、Week 1 で原文を確認します。**

### 他の案を選ばなかった理由

| 案 | 粗利1億に届くか | 判断 |
|----|---------------|------|
| Web受託の延長（飲食・美容） | 粗利1億には単価56万円で**年250件**必要。代表が制作すると年30件が上限 | ✕ 資金源として残し、縮小していく |
| farm-app を農家向けSaaSにする | 農家が払える額は月数千円。粗利1億には**2,000戸以上**必要。作物の周期で検証も遅い | ✕ 18ヶ月凍結 |
| ぶどうの木会員権・就農コンサル | 数を増やすほど代表の時間を取られる。収穫に合わせて年1回しか回らない | ✕ 凍結（ブランド・発信としては続ける） |
| **接骨院向け月額サービス** | **月4.8万円 × 250院**で届く。代表が手を動かさなくても数を増やせる | **◎ 採用** |

**連続起業家として一番伝えたいこと: 4つの事業を並行していては、どれも粗利1億には届きません。**
3年間はこの1本に絞ってください。

## 2. 数字の設計 — 粗利1億を逆算する

### 商品と価格

| | 初期構築 | 月額 | 内容 |
|---|---------|------|------|
| **スタンダード** | 19.8万円 | **3.98万円** | ガイドライン準拠サイト、Googleビジネスプロフィール最適化、構造化データ（AEO）、LINE予約、来院後の口コミ依頼の自動化、月次レポート |
| **プロ** | 29.8万円 | **6.98万円** | スタンダード＋自費メニューの設計、回数券EC、LINE配信の代行、毎月の数値面談 |

- 想定比率 7:3、値引き後の平均単価（ARPA）**4.8万円/月**
- 初期費用は平均15万円で計算（創業パートナー院・キャンペーンの値引き込み）
- 最低契約6ヶ月。解約率は**月1.5%**（年17%）で計画。2%を超えたら対策（第6章）

### 3年間の数字

| | 1年目（〜2027/9） | 2年目（〜2028/9） | 3年目（〜2029/9） |
|---|---|---|---|
| 期末の契約院数 | 40 | 130 | **250** |
| 月あたり新規 | 4院 | 9院 | 13院 |
| 期末の月額売上（MRR） | 192万 | 624万 | **1,200万** |
| 月額分の粗利（粗利率80%） | 約830万 | 約3,900万 | 約8,750万 |
| 初期費用の粗利（粗利率60%） | 約400万 | 約950万 | 約1,390万 |
| Web受託（値上げ後、縮小） | 約350万 | 約100万 | 0 |
| **年間粗利** | **約1,600万** | **約4,950万** | **約1.01億** |

3年目の期末には、月額分だけで**粗利の年換算が1.15億円**になり、4年目以降は何もしなくても1億を超えます。

### 1院あたりの採算

| 指標 | 目標 | 根拠 |
|------|------|------|
| 粗利率 | 80% | 運用担当1人で60院を担当（人件費は売上の14%）、ツール・AI費が7% |
| 導入にかかる時間 | **8時間/院以下** | テンプレートと自動化で、今の92時間/件から1/10以下に |
| 獲得コスト（CAC） | 15万円以下 | パートナー紹介料は月額3ヶ月分を1回だけ払う（毎月の手数料にはしない） |
| LTV | 約256万円 | 4.8万 × 80% ÷ 1.5% |
| LTV/CAC | **17倍** | 3倍以上あれば健全。余裕があるので、獲得に投資できる |

**粗利率80%を守れるかどうかは、1人の運用担当が60院を見られるかで決まります。**
ここが代表の技術力の生かしどころです（月次レポート、Googleマップの投稿、口コミへの返信案、FAQの更新を AI で下書き → ガイドラインのルールでチェック → 人が確認）。

## 3. 戦略 — 3年の段階

### Phase 0: 検証（2026年10月・1ヶ月）
**このまま進めてよいかを、お金を払ってもらえるかで確かめる。** → 詳細は第5章

### Phase 1: 最初の10院（2026年11月〜2027年3月）
- 創業パートナー院 5院 → 有料10院
- 決めること: **「導入後90日で、Googleマップ経由の新患が何人増えたか」という成果の数字を、実績として3つ作る**
- 導入作業をテンプレート化し、8時間/院以内に収める（今のサイト制作の型を流用）
- Web受託は値上げ価格（加重平均56万円）で、紹介案件だけ受ける。納品済みの2社には月額保守を提案する

### Phase 2: 売り方を作る（2027年4月〜2028年3月・〜80院）
- **業界のパートナー経由で売る仕組みを作る**（第4章）。代表が自分で売らなくても月5院以上入る状態に
- 運用担当（業務委託→正社員）を2名。インサイドセールス1名
- 機能追加: 回数券EC（資金決済法の6ヶ月ルール、TODO E5）、自費メニューLP、問診のLINE化

### Phase 3: 増やす（2028年4月〜2029年9月・〜250院）
- 運用担当4名、インサイドセールス2名、パートナー担当1名、エンジニア1名
- 隣の業種へ同じ商品を広げるのは**150院を超えてから**（整体院・鍼灸院 → 動物病院）。それまでは広げない
- 4年目に向けて、販売を任せて代表は商品と採用に専念

## 4. 戦術 — どうやって売るか

### 集客チャネル（3年目の構成比）

| チャネル | 構成比 | 具体策 |
|---------|-------|--------|
| **業界パートナー** | 50% | 治療器ディーラー、レセコン・会計の販売会社、開業コンサル、柔整専門学校のOB会。紹介料は月額3ヶ月分を1回払う。**相手にとって「規制で広告を売れなくなった顧客に出せる次の商品」になる** |
| **院からの紹介** | 25% | 導入90日後に成果を報告するタイミングで紹介を依頼（Web事業の09章と同じ型）。紹介した院は1ヶ月無料 |
| **無料チェックツール経由** | 25% | **「広告ガイドライン セルフチェッカー」**: 院のサイトURLを入れると、ガイドライン上の注意点と Googleマップ・AI検索での見つかりやすさを採点する。結果を見た院が相談に来る |

**やらないこと:** 一斉DM・テレアポ（コールドは0.5〜5%、09章で実証済み）。広告運用の提案（ガイドライン違反のおそれ）。

### チェックツールが一番の武器になる理由
- 院長が「自分のサイトは大丈夫か」と不安なタイミングに、無料で答えを出せる
- パートナーが顧客を訪問するときの**手土産**になる（「このツールで診断してみませんか」）
- 「AI検索に対応します」と言う会社が、実際に AI を使って診断して見せる、というデモになる
- 作るのに2〜3日。代表なら Next.js と Claude API で作れる
- ⚠ 結果は「セルフチェックの目安」と表示し、法的な判断はしない。文言は行政書士に一度見てもらう

### 営業の型（商談30分）
1. チェッカーの結果を一緒に見る（5分）
2. 療養費改定と広告規制の話 → 「自費の患者を自分で集めるしかない」（5分）
3. 現在の集客費を聞く（ポータル・チラシ・コンサル）→ 年額にして比べる（10分）
4. 90日後に何人増やすかを一緒に決め、プランを選ぶ（10分）

## 6. リスクと対策

| リスク | 兆候 | 対策 |
|-------|------|------|
| 月3.98万円では高いと言われる | Week 3 の申込みが0〜1 | 「今の集客費の中で置き換える」形で提案し直す。それでも駄目なら業種を変える（Week 4 の表） |
| 成果が出ず解約される | 月の解約率が2%を超える | 導入90日で成果が見えるよう、Googleマップの最適化と口コミ依頼を最初の30日に集中させる |
| ガイドラインの解釈を誤る | 院から指摘・行政から照会 | 原文に基づくチェックリストを作り、四半期に一度、行政書士に確認してもらう。表現の最終判断は院長に |
| 代表の時間が足りない | 導入が8時間/院を超える | 1年目に運用担当（業務委託）を1名。導入作業はテンプレート化してから人に渡す |
| Google・AI検索の仕様変更 | 診断スコアと新患数がずれる | 特定の施策に頼らず、サイト・Googleマップ・LINE・口コミの4つに分散させておく |
| 農業側の仕事と時期が重なる | 収穫期に商談が止まる | 繁忙期を年間カレンダーに先に入れ、その月は導入を受け付けない |
