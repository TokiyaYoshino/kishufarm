## C. 再現する形（まっち型の4部品）

| 部品 | 中身 | 役割 |
|---|---|---|
| ① 自分の畑 | 自社の玉ねぎ | 「農家本人」という立場と発信のネタ |
| ② **他農家の販売代行** | 近隣農家の作物を売る（まっちさんは2022年の起業時から） | **売上の主力。自分の収量と作期に縛られない** |
| ③ 値決めできる販路 | 飲食店へ週次直接納品＋通販 | 卸では付加価値が認められない構造からの脱出 |
| ④ 人ブランド | 顔と名前での発信 | ①〜③の集客＋企業案件という別収益 |

**②が効く理由**：玉ねぎは年1作で、まる曽の自社玉ねぎは2027年春の収穫。②なら**収穫を待たずに今季から売上が立つ**。②は霧珠ファームのWeb支援事業と同じ構造なので、**まる曽が自社の実証事例になる**。

### 代行型 vs 買取型
| | 買取型 | **代行型（採用）** |
|---|---|---|
| 利幅 | 大きい | 手数料のみ |
| 在庫・ロスリスク | 自分が負う | **無い** |
| 運転資金 | 必要 | **ほぼ不要** |
| 食品表示の責任 | 自分が負う | 農家側に残る |
| インボイスの影響 | 大きい | **小さい** |

| **2028年** | 企業案件・メディア・加工品。買取型への移行を検討 | 玉ねぎ以外の収益が立つ |

まっちさんは起業（2022）→フォロワー10万・企業案件（2025.4）で約3年。**①②③の売上は発信を待たずに立つため2028年10月に間に合うが、②を2026年内に始めないと間に合わない。**

### D-2. 差別化の理由を決めるための確認項目

**今すぐ確認できる（紙と伝票）**
- [ ] **経営の数字（最優先）**：年間出荷量／販売先構成比／直近3年の手取りkg単価／規格外の発生率
- [ ] **防除暦**：使用年月日・場所・作物・農薬名・希釈倍数（省令の帳簿5項目。努力義務で罰則なしだが出荷先対応で事実上必要）
- [ ] **施肥設計**：化学肥料の窒素成分量（kg/10a）
- [ ] **都道府県の慣行レベル**を入手し突き合わせ → 節減対象農薬の使用回数と化学肥料の窒素量が**両方とも慣行比50%以下なら特別栽培農産物として表示可**
- [ ] **品種名**：種子の袋・購入伝票から。品種別の作付面積と収穫期
- [ ] **出荷カレンダーと貯蔵**：過去2〜3年の収穫開始〜終了日／貯蔵設備と容量／貯蔵後のロス率
- [ ] **商標**：「まる曽」＋商品名が空いているか（J-PlatPat）

**収穫期（2027年春）まで測れない**
- 糖度：Brix計で収穫直後に無作為20玉、**平均だけでなく最低値も記録**。品種・窒素量・貯蔵期間で動くため時期をずらして2回
- → **11月末に軸を決めるならAは候補から外れる**

**判定**：①の数字 → 慣行レベルとの突き合わせ。50%以下に届く、または今季の施肥・防除を寄せれば届くなら**Bで確定**。届かないなら**D（出荷時期）**。
今は播種〜定植期で施肥設計をこれから決める段階なので、**Bは「確認する」だけでなく今季から作れる軸**（蜜玉がこの型）。

### D-3. 11月にやること
- [ ] 商圏の確認（片道何分圏に飲食店が何軒あるか。まっち型は「毎週配達できる距離」が前提）
- [ ] 仕入先候補20件（近隣の高齢農家）
- [ ] 売り先候補20件（飲食店・小売・直売所）
- [ ] 代行型で1農家 × 1売り先の最小ループを回す（玉ねぎ以外の品目でよい）
- [ ] 産直モールに出品して反応と価格を見る
- [ ] 発信を開始（§E）

**営業の軸**：卸では付加価値が認められにくいのが共通の出発点。**週次の定期納品と規格の融通を引き受ける代わりに、値決めはこちらが持つ。**

## E. SNS発信の運用フロー

| 項目 | 決定案 |
|---|---|
| プラットフォーム | **TikTok ＋ Instagram の2つだけ**（同じ縦動画を両方に）※未決B-3 |
| アカウント名 | **「呼び名｜まる曽のたまねぎ」** ※呼び名が未決B-4 |
| 本数とリズム | **週4本**（火・木・土・日の19時前後に予約投稿） |
| 見る数字 | **保存数**と**プロフィールアクセス**のみ、週1回記録。フォロワー数は販売期まで追わない |
| 最低ライン | 販売期（2027.2〜4）までに**60〜70本**。11月開始が実質の締切（12月開始だと40本台） |

### 投稿の4柱（これ以外は投稿しない）
| 柱 | 中身 | 比率 |
|---|---|---|
| A 現場 | 作業・収穫・畑の景色・機械 | 4割 |
| B 食べ方 | 調理・保存・切り方・部位の使い方 | 3割 |
| C 知識 | 選び方、保存法、品種の違い、裏話 | 2割 |
| D 人 | 看板役の素顔・失敗・日常 | 1割 |

**売る投稿は5本に1本まで。** 差別化の理由が決まるまではA・B・Dの3柱で回し、固まったらC柱に乗せる。

### 週の固定フロー
1. **畑に行く日（週1〜2回）＝まとめ撮り**：1回で10〜15本分。縦9:16、1本15〜30秒、必ず声を入れる
2. **夜に編集2本**（1本10分以内。撮って出し8割で出す）
3. **予約投稿で週4本**
4. **コメント返信を毎日10分**（定着に最も効く）

### やらないこと
- **顔を出さない**（人ブランドが成立しない。譲れない前提）
- **完璧に作る**（編集1本10分を超えたら止まる）
- **柱を増やす**／**売り込みの連続**

## F. 法務・税務（②を始める前に）

| 論点 | 内容 |
|---|---|
| **食品表示** | 生鮮食品は**名称と原産地の表示が義務**。業者間取引も対象。複数産地を混ぜる場合は**重量の多い順に全産地**。バラ売りは近接掲示可。容器包装に入れて売るなら事業者名・住所の表示が関わるため**保健所・農政事務所に確認** |
| **表示の禁止** | **「無農薬」「減農薬」「無化学肥料」「減化学肥料」は禁止。** 正しくは「節減対象農薬：○○地域比5割減」「栽培期間中不使用」。**「有機」「オーガニック」は有機JAS認証なしでは違法** |
| **インボイス** | 免税農家からの仕入れは控除が制限。2026年10月1日が転換点で、控除率は解説により**「80%→70%」と「80%→50%」で食い違う**。判定は支払日でなく**取引日**。買取型を検討する段階で**国税庁の公式資料で確認**。代行型なら論点は小さい |
| **営業許可** | 生鮮をそのまま売る限り不要。**カット・加工・瓶詰めをした時点で食品衛生法の許可が必要** |
| **農薬** | 使用基準は**ラベルの表示が最終的な正**。散布回数を削る場合はJA営農指導員か普及指導センターに相談 |
