# 「まる曽玉ねぎ」調査メモ（リブランディング前の現状把握）

調査日：2026-10-25　／　方法：Web検索のみ（現地・関係者への聞き取りはまだ）

## 結論（先に）

**ブランドは「ある」。ただし、知られているのは地元・行政・取引先の中だけで、一般の消費者にはほとんど知られていない。**

- 名前・物語・産地組織・加工品・年1回のイベントまで揃っていて、ゼロから作る段階ではない
- 一方で、公式サイト・SNS・自前の通販・一般の人の口コミが検索ではほぼ見つからない
- そのため、進め方は「新しく名前を付ける」ではなく、**今ある名前と物語を磨いて、外へ届ける（再ブランド化）**になる

## 1. 検索での出方

「まる曽 玉ねぎ」で検索すると、すぐに**京都府亀岡市曽我部町の玉ねぎ**だと分かる。同じ名前の別商品とは混ざらない。

| 亀岡市の資料（給食・収穫祭の告知） | 給食のハンバーグに使用、収穫祭の案内 |

**見つからなかったもの**
- 生産者側の公式サイト・Instagram などのSNS
- 玉ねぎそのもの（青果）の通販・ふるさと納税の返礼品
- 一般の人のブログ・レビュー・口コミ

**表記がばらばら**：「まる曽」「○曽」「〇曽」「まるそ」が混在している。検索で取りこぼす原因になり、リブランディングで最初に直す点の候補。

## 2. これまでの歴史

| 時期 | 出来事 |
|---|---|
| 約50年以上前〜 | 曽我部町を中心に玉ねぎの生産が本格化。京都の中央市場で高く評価された |
| 昭和37〜38年ごろ（1962〜63年） | 生産のピーク。乾燥用の**吊り小屋が約300棟**（1棟約5トン → 推計約1,500トン） |
| その後 | 兼業化・高齢化・後継者不足・設備の老朽化で生産が激減。吊り小屋は12棟まで減った |
| 2014年度〜 | 国営の農地整備事業（亀岡中部地区）が始まり、田んぼの区画が大きくなる。米以外の稼げる作物として玉ねぎが再浮上 |
| 2016年 | 地元の農業振興協議会とJAが初めての生産振興研修会を開く |
| 2018年 | 4集落26人で「曽我部町玉ねぎ栽培グループ」が発足 |
| 2019年 | 6集落に拡大。石井食品と組んでハンバーグ・スープを発売（亀岡市長も出席した試食会） |
| 2021年3月 | 6集落合同の営農組織「**まる曽れい仙の郷**」を設立。移植機・収穫機を導入し、商品名を「まる曽玉ねぎ」として復活。その後、栽培グループなどを法人化 |
| 2021年7月 | 第1回「まる曽玉ねぎ収穫祭」 |
| 2026年7月11日 | 第5回収穫祭。100円の詰め放題に行列、石井食品のハンバーグを先行販売 |

**売りとして語られていること**
- 曽我部町で昔から作られてきた固有の玉ねぎ
- 盆地の昼夜の寒暖差と、収穫後に吊り小屋で干す伝統製法。干すことで糖度が約8度から約10度に上がる
- 甘く、シャキシャキしていて、表面につやがある。生より加熱向き（輪切りのソテーがおすすめ）

## 5. 進め方の選択肢（推奨つき）

1. **【推奨】今ある名前と物語を磨いて外へ届ける**：表記を1つに統一し、吊り小屋・糖度の話を軸に、公式の発信先と青果の買い口（通販・ふるさと納税など）を作る。石井食品の全国通販という既にある入口とつなげる
2. **名前から作り直す**：新しい名前とロゴで出直す。ただし、行政記事・新聞・メーカー商品に「まる曽」が5年以上積み上がっているので、それを捨てることになる。勧めない
