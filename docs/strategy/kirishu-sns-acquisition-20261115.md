## 1. 最初に力を入れる媒体（2〜3つ）

### 過去に話したこと
- まる曽の計画：**TikTok＋Instagram の2つ**
- 会員権の計画：媒体ごとに役割を分けていた

| 役割 | 媒体 |
|---|---|
| 知ってもらう | TikTok、Instagram |
| 信頼してもらう | YouTube（余力ができてから） |
| 囲い込んで売る | **LINE** |

- まる曽の直販調査の結論：**「見せるのは Instagram、知らせて買ってもらうのは LINE」**。玉ねぎを10kg単位で買うのは40〜60代で、60代の LINE 利用率は91.1%（Instagram は60代で34.7%）

### 推奨
- **フォロワーを増やす2つ：Instagram と TikTok**
- **売るための受け皿：LINE**
- YouTube と X には同じ動画を出すだけにして、コメント回りなどの手間はかけない

もう一つの案は Instagram と YouTube に絞る形。ただし TikTok は新しい人に広く届くので、ゼロから始める今は外さないほうがよい。

## 2. コメントやリプライをする相手

### 過去に話したこと（11月実務キットで決定済み）
優先順位：
1. 同じ品目の農家
2. 同じ地域の農家（品目は問わない）
3. その作物を使う飲食店（将来の売り先になる）
4. 農業系の発信者で、フォロワー1,000〜5万人の人（返事が返ってくる層）

- フォロワー10万人超は返事が来ないので後回し
- **やらない**：宣伝・リンク／絵文字だけ／「素敵です」だけ／フォロー返しのお願い
- コメントの型：A 共感＋自分の状況／B 答えやすい質問／C 自分の数字を1つ出す

### 競合や同業界でもいいか
**良い。むしろ最初の入口はそこ。** 同業の農家をフォローしている人は、もともと農業や食に興味がある層。その人たちの目に入る場所で、ちゃんとした会話をしているのが一番効く。

### 今回足す相手
会員権があるので、次を足す：
- **ワイン好きのアカウント**
- **亀岡の地元アカウント**（観光・飲食店）

## 3. 最初の立ち位置（ぶどう・まる曽・会員権）

### 過去に話したこと（2つの資料で分かれたまま）
- まる曽の計画：人を前に出した「呼び名｜まる曽のたまねぎ」という専用アカウント
- 会員権の計画：霧珠ファームとして「自分の木が育つ物語」を発信。**植え付け日を第1話・記念日にする**
- 会員権の調査：「植えてから初収穫までの3年を通して発信している日本のアカウントは見つからなかった。**この切り口は先に取れる**」
- 売上目標：作物は「発信の材料と、会員権の特典（季節便）」という位置づけ。自社のSNSは売上に数えず、会員権と作物を売る道具として扱う

### 推奨：アカウントは1つにして、ぶどうの木を植えるところを話の軸にする
- 立ち位置は「**亀岡で、ぶどうの木を植えるところから始める農家**」
- まる曽の玉ねぎや万願寺は「この農家が季節ごとに育てている作物」として同じアカウントに出す
- 会員権は「この木を一緒に育てる権利」として、この話の延長で売る
- 理由
  - フォロワーゼロからアカウントを分けると、手間が倍で伸びは半分になる
  - **植え付けは今月（2026年11月）。第1話を撮れるのは今だけ**

もう一つの案は、計画どおりまる曽を別アカウントで育てる形。まる曽の販売代行が本格的に回り始めたら、そのときに分けても遅くない。

## 4. 直販とクラウドファンディングの売り場（農家がどこでどう動いているか）

### 過去に調べたこと

| 売り場 | 客層と実績 | 農家の動き方 |
|---|---|---|
| **食べチョク** | 会員125万人。手数料19.7%で、送料には掛からない | 収穫前に「【2027年予約】」と付けて出品し、予約を集める |
| ポケットマルシェ | 手数料23% | ほぼ同じ |
| **CAMPFIRE** | 神戸の新しいワイナリー「ドメーヌ他火」は、初回で369人から約545万円（目標400万円の136%） | 客がいない状態で出した玉ねぎ機械化のクラファンは、支援10人で不成立 |
| **ふるさと納税型のクラファン（ふるなびなど）** | 大阪・泉佐野の玉ねぎ農家（射手矢農園）は寄附者3,801人 | 自治体を通して出す |

**クラファンで集まる額は、物語よりも「すでに持っているお客さんの数」で決まる。** ポケマル1位の生産者は、既存の客にまとめて知らせて開始2日目で目標の約半分に届いた。新規参入が1年目にクラファンを主軸にするのは順番が逆。

### 今回新しく分かったこと：亀岡市「ふるさと産品創出等支援事業」
- 市が**ふるさと納税の仕組みでクラファンを行い**、地域ブランドになる産品をつくる事業者を補助する制度
- ふるさと納税の利用者は、もともと「食べ物を選んで買う人」。**食や農業に興味がない人ばかりで直販が見込めない、という問題をそのまま避けられる**
- 市への寄附は令和7年度（速報値）で約44.3億円・11.5万件
- 応募の条件
  - **事前相談が必須**。相談先は商工観光課（0771-25-5033）
  - 募集期間は 3/19〜4/30、採択は5月中旬〜下旬（資料に年度の表記が無かったので、最新の要項で日程を確認する）
  - 審査は採算性・目標達成の可能性・返礼品としての適性など。CF目標額に届かなくても事業の実施が条件

### 推奨
1. 最初の買い手は**食べチョク**で拾い、買ってくれた人を LINE に集める
2. クラファンは、**亀岡市のふるさと納税型**を第一の候補にする。2027年春の募集を狙い、冬のうちに事前相談に行く
3. CAMPFIRE は、LINE の登録者が数百人になってからにする

## 5. ふるさと納税と地域ブランドに向けて、今できること

### 過去に調べたこと
- ブランド化の型は**人ブランド・商品ブランド・産地ブランド**の3つ
- 地域団体商標と GI（地理的表示）は**生産者団体が取るもので、1軒の農家では取れない**。淡路島たまねぎは地域団体商標まで約120年
- 決める順番は「**人の呼び名 → 差別化の理由 → 商品名**」
- 在来の玉ねぎで一番近い先例は**札幌黄**。栽培農家が10戸程度まで減ったあと、ファンクラブ（2012年）→ 翌年度に協議会 → 31戸まで回復
- まる曽にはすでに営農組織「**まる曽れい仙の郷**」がある
- ふるさと納税の手続き：返礼品を決めるのは自治体で、事業者は自治体の募集に応募する。**返礼品の価値は寄付額の3割以下**（年3万円の会員権なら寄付額10万円。りんごの木オーナー10万円の例と同じ水準）。寄付者の連絡先は自治体が管理するので、発送物に LINE の QR を入れて補う

### 今できること（効く順）
1. **亀岡市の商工観光課に相談を入れる。** ふるさと納税の返礼品への登録と、上の支援事業の両方を一度に聞ける。会員権をりんごの木オーナーと同じ形で出せる可能性がある
2. **「霧珠ファーム」と、今後決める商品名の商標登録を検討する。** 1軒でも取れる唯一の権利
3. **京都府の「京のブランド産品」を確認する。** 京のふるさと産品協会が認証している制度。万願寺が対象になるか問い合わせる価値がある（未確認）
4. **まる曽の産地ブランドは、「まる曽れい仙の郷」を通した札幌黄型を目指す。** ファンクラブ → 協議会 → 商標の順。1軒で狙うものではない
5. **地元紙に載る機会が来たら、記事に「予約は LINE で」の QR を入れてもらう。** 話題をお客さんの名簿に変えるため
