# 完売を繰り返す農家は先に名簿を作った

> **数字の扱いについて（先に読んでください）**：調査担当の環境では各ページの本文を開けず、**すべて検索結果の抜粋から拾った数字**です。1つの抜粋にしか出てこない数字には「要確認」の印を付けました。また、SNS支援会社・ツール会社・販路支援会社が自社の宣伝として書いた事例は**裏付けが弱い**ので、表では「支援会社の宣伝」と分けています。値段や手数料は掲載時点のものです。災害・コロナの「助けてください」型（以下SOS型）と、ふるさと納税型のクラウドファンディング（以下クラファン）は、ふつうの商品販売と条件が違うので、別の表に分けました。全項目がそろわない欄は「不明」と書き、埋めた振りはしていません。調査日は2026-10-25。

**結論：まる曽玉ねぎは「年1回の予約販売」と「吊り小屋オーナー（体験つき）」を、LINE公式アカウントに集めた名簿へ売るのがよい。最初の買い手は食べチョクで拾う。** 数字が確かめられた事例を並べると、何度も完売を繰り返しているのは、一度のバズ（投稿の大当たり）で売れた農家ではなく、**予約の名簿を先に持っていた農家**だった。千葉のしあわせスイカ農園は「例年、受付開始から1分以内に完売」し、愛媛の津和地島（人口約300人）の新玉ねぎは5kg 5,480円でも販売当日に売り切れ、果樹のオーナー制度では1園約100組のうち9割が翌年も続ける。逆に、1,000万円を超えた玉ねぎのクラファン2件（熊本のKAMA FARM 2,026万円、大阪の射手矢農園 1,983万円）は、どちらも水害の復旧とふるさと納税という特別な条件で集まったお金で、普通の商品販売として出した玉ねぎのクラファンは数十万円規模にとどまる。玉ねぎそのものを「SNSから何分で何箱完売」と数字で報じた名前つきの事例は、今回も見つからなかった。だから最初の3か月（2026年11月〜2027年1月）は、売上を追うより、**吊り小屋の使い方を産地組織に確かめ、LINE名簿を30人以上つくり、1月に2027年産の予約とオーナー募集を開く**ことに絞る。

### 二つの表から読めること

表1で「毎年」完売している事例（しあわせスイカ、津和地島、オーナー制度）と、一度だけ売れた事例（OKファームのバズ、SOS型）を分けるのは、**買った人の連絡先を次の年まで持っているかどうか**である。OKファーム本人も「SOS的な呼びかけを2回続けると信用を失う」と話しており ([LISTEN](https://listen.style/p/ok-farm/oc7kkeun))、食べチョクのコロナ企画で売れた3トンも、半年後には生産者の6割がまだ売上の影響を受けていた ([PR TIMES](https://prtimes.jp/main/html/rd/p/000000084.000025043.html))。もう一つの共通点は、売れた事例が**バズより前に注文の受け皿を用意していた**ことで、OKファームは投稿の前夜に注文ページを書き上げ、ファームキムラはLINEと定期便を組んでから公開している。

数字の大きさにも注意がいる。表1で売上額まで分かるのはネギニキ（年1,500万円以上）とミヤハラ農園だけで、どちらも生の野菜ではなく**加工品かライブでのまとめ売り**で単価を上げている。単価の安い生野菜をそのまま売った事例で金額が残っているものはほとんどない。玉ねぎに限ると、確かな単価があるのは津和地島（5kg 5,480円）と農家の孫まっち（5kg 2,200〜3,550円）で、その差は「島の幻の玉ねぎ」という物語の強さにほぼ対応する。フォロワー数の目安は、約1,000人で「直接売ってほしい」という連絡が来始め ([糸満フルーツ園](https://okinawan-avocado.com/2020/01/08/agri_sns_insta/))、5,000〜6,000人で年1回の予約を売り切った例がある（マンゴーオジー、支援会社の宣伝）。ただしマンゴーやスイカは贈答向けの高い果物なので、5kg 2,000〜3,000円台の玉ねぎにそのまま当てはめるのは危ない。

クラファンは魅力的に見えるが、数字を分けて読むと、**集まった額を決めているのは物語より「すでに持っている客の数」**である。ポケマル1位の生産者は、既存の客にまとめて知らせて開始2日目で目標の約半分に届いた。逆に、客を持たずに出した玉ねぎ機械化のクラファンは10人で不成立に終わっている。新規参入の私たちが1年目にクラファンを主軸にするのは順番が逆で、名簿が数百人になってから「吊り小屋の修繕」などの節目に出すのが先例に沿う。

## 伝統の玉ねぎで「名簿より先に話題」を作った産地は、話題を売上に残せていない

在来の玉ねぎで一番近い先例は札幌黄で、栽培農家が一時10戸程度まで減ったあと、2012年のファンクラブと翌年度の協議会を経て31戸まで戻った ([JAさっぽろ](https://www.ja-sapporo.or.jp/agriculture/traditional/sapporo-yellow/))。ただし、ここでもSNSは補助役で、生産者の直販の数字は見つからなかった。まる曽玉ねぎ自体も、2018年に4集落で生産を再開し、2019年に6集落、2021年3月に営農組織「まる曽れい仙の郷」ができ、石井食品の加工品や亀岡市長の発案で話題は作ってきた ([PR TIMES](https://prtimes.jp/main/html/rd/p/000000031.000034294.html)、[近畿農政局](https://www.maff.go.jp/kinki/tiiki/kyoto/Maruso220826.html))。それでも生産量・販売額・個人向け直販の割合は公表されておらず、一般の消費者にはまだ知られていない。つまり、**行政や企業の発表は「信用の裏付け」にはなっても、それだけでは個人の買い手の名簿は残らない**。

この点で、まる曽の私たちが真似すべきなのは、話題の大きさではなく、津和地島やしあわせスイカ農園のように**「毎年この日に予約が開く」という約束を名簿に向けて繰り返すこと**だと考える。京都新聞が収穫祭を取り上げるような機会が来たとき、記事に「予約はLINEで」のQRを入れてもらえれば、話題が名簿に変わる。ただし、地方紙に載った後に登録者がどれだけ増えたかを測った事例は見つかっておらず、これは筋の良い推測にとどまる。

「まる曽」の名前は、私たちの発信と商品名に使ってよいことが確認できている（2026-10-25 オーナー確認）。残る前提は吊り小屋で、オーナー制度や体験で使うなら、小屋の持ち主と組織の了解が要る。

## 推奨：予約販売と吊り小屋オーナーをLINE名簿で売る

選択肢は二つに絞る。

**【推奨】A. 「2027年産の予約」と「吊り小屋オーナー（体験つき）」を、LINE名簿に向けて年1回売る。最初の買い手は食べチョクで拾う。** 理由は三つある。第一に、表1で毎年完売を繰り返しているのはこの型だけで（しあわせスイカ、津和地島）、オーナー制度にはリピート9割という継続の数字がある。第二に、代金を収穫前に受け取れるので、新規参入で一番怖い「作ったが売れない」を避けられ、収穫見込みに合わせて上限を決められる（マンゴーオジーは受けすぎて受付を3回に分けた）。第三に、オーナー区画と体験は送料がかからず、玉ねぎ直販の一番の弱点である送料負け（10kg箱で商品代の約3割）を避けられる。値段は、予約の生玉ねぎを送料別で5kg 2,500円・10kg 4,000円前後から試し、オーナーは小田原の「1区画5,000円・約200玉」を物差しに、吊り干し体験の分を上乗せして決める（どちらも前例からの試し値で、裏付けのある最適値ではない）。仮に1年目が予約50箱（5kg 2,500円）とオーナー30区画（1区画6,000円）だとしても、売上は約30万円で、2525ファームの1年目350万円にも遠く及ばない。この規模は推測であり、1年目は**名簿の人数と翌年も申し込む割合**で成否を見る。

B. 2027年の収穫期にクラファン（吊り小屋の再生をテーマ）で一気に立ち上げる。うまくいけば数十万〜数百万円をまとめて集められ、メディアの話題にもなる。しかし数字を見る限り、集まる額は既存の客の数で決まり、客のいない状態では不成立の危険が大きい（不成立10人の例、目標の68%で終わった在来種の例）。**名簿が数百人に育つ2年目以降に、Aの上に重ねる手として取っておく。**

ふるさと納税と料理店との協力は、Aの邪魔をしない範囲で並行して問い合わせるにとどめる。ふるさと納税は寄附者の連絡先が手に入らず、料理店は量が少ないうちは個人向けと玉ねぎを取り合うからだ。加工品とライブ配信は、生産量と冬の見せ場が増えてからでよい。

## 2027年に出す量と売上の概算（作付面積10aあたり）

私たちの作付面積がまだ分からないので、**10a（1反）あたり**で概算する。面積が決まれば、この表を倍にするだけでよい。収量は一般的な目安からの仮定で、まる曽の実績値ではない。

**取れる量**

| 項目 | 概算 | 置いた仮定 |
|---|---|---|
| 収穫量 | 約4t | 玉ねぎの10aあたり収量は全国でおおむね4〜5t。新規参入なので低い側を取る |
| 吊り干し・貯蔵での目減りと規格外 | 約1t減 | 乾燥による目減り、腐敗、小玉・傷を合わせて約25% |
| **個人に売れる量** | **約3t** | 10kg箱なら約300箱、5kg箱なら約600箱 |

**1年目に個人へ売れる見込み**：量より買い手の数で上限が決まる。1月時点のLINE名簿は30〜100人の想定で、事例からは名簿の何割が予約するかの数字が取れていないため、下の2案は仮定である。

| | 控えめ | 目標 |
|---|---|---|
| 予約の生玉ねぎ（5kg 2,500円・送料別） | 50箱（250kg） | 150箱（750kg） |
| 吊り小屋オーナー（1区画100玉・約25kg・6,000円・体験つき） | 10区画（250kg） | 30区画（750kg） |
| 売上 | 約18.5万円 | 約55.5万円 |
| 食べチョク経由分の手数料（19.7%）を全量に掛けた場合の手取り | 約15万円 | 約45万円 |
| 個人に売れる量（約3t）のうち個人向けに回す割合 | 500kg・約2割弱 | 1.5t・約5割 |

- **残りの5〜8割は、JAや既存の出荷先に出す前提**で作付けする。個人向けは「名簿の人数に合わせて上限を決める」売り方なので、作った量を全部個人で売ろうとしない
- **オーナー区画は量あたりの売上が低い**。小田原と同じ「1区画約200玉（約50kg）」を6,000円で出すと、同じ量を5kg箱で売る場合（約2.5万円）の4分の1になる。そのため上の表は**1区画100玉（約25kg）**で置いたが、それでも5kg箱5箱分（12,500円）の約半分。オーナーは売上でなく常連づくりの商品と割り切る。100玉の区画は株間・通路込みで約5㎡（仮定）なので、30区画でも約1.5aで収まる
- 2年目は、1年目の予約者が戻る割合（オーナー制度の事例ではリピート約9割）と名簿の伸びを見て、個人向けの割合を上げる

## 結論

今回の調査で考えが変わったのは、「SNSで話題になれば売れる」という前提が、数字の上ではほとんど支えられていなかった点である。大きな金額が動いた玉ねぎの事例は、災害・コロナ・ふるさと納税・テレビといった外からの追い風に乗ったもので、平時に毎年売り切っている農家は、派手な投稿ではなく「毎年この日に開く予約」と「その知らせを受け取る名簿」を持っていた。まる曽玉ねぎにとって、吊り小屋は写真の背景ではなく、オーナーや体験として売れる商品そのものであり、送料のかからない売り物でもある。

「まる曽」の名前は使ってよいと確認できた。残る不確かさは、吊り小屋を体験に使えるか、作付面積（10aあたりの概算に掛ける数）、5kg箱の送料と梱包の実額の三つで、どれも検索では分からない。11月第1週に産地組織へ聞いて面積を決め、12月に1箱送ってみれば確かめられる。調べる段階は終わり、人に聞いて手を動かす段階に入っている。
