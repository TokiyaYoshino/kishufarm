# マーケ判断ログ・月次報告の型

> **一行で**：現職マーケで「判断と結果責任」を見える形で残し、1年後の業務委託の提案材料にする。
>
> 目標：2028年10月までに個人年収1000万円（現職マーケを業務委託・週2日で継続）
> 作成：2026-11-09
>
> **注意**：会社の数字・顧客情報はこのリポジトリに書かない。この型を会社のスプレッドシート等に写して使う。

---

## 考え方：作業は渡し、判断は持つ

| | 手放す（相方ができる状態にする） | 残す（自分にしかできない） |
|---|---|---|
| 中身 | 決まった手順で回る**作業** | 何をやるか決める**判断** |
| AEOの例 | 記事投稿、構造化データのテンプレ適用、月次の数値集め | どの質問を狙うか、施策の優先順位、AI検索の仕様変更への対応、結果の読み解き |
| 会社から見ると | 「辞められたら止まる」＝リスク | 「この人がいると伸びる」＝価値 |

判断の流れ：**① 見立て → ② 選ぶ（やる／やらない） → ③ 任せる → ④ 測る → ⑤ 直す → ①へ**

---

## 1. 判断ログ（施策ごとに1行）

判断したらその場で1行書く。**「やらない」と決めたものも書く**（判断力が一番出るところ）。

| 日付 | 施策 | 判断 | 理由（根拠の数字・事実） | 狙う数字（KPIと目標値） | 見直し日 | 結果 | 次の判断 |
|---|---|---|---|---|---|---|---|
| | | やる／やらない／保留 | | | | | 続ける／変える／やめる |

**記入例**（数字は架空）

| 日付 | 施策 | 判断 | 理由 | 狙う数字 | 見直し日 | 結果 | 次の判断 |
|---|---|---|---|---|---|---|---|
| 11/10 | 主要サービスページにFAQ構造化データを追加 | やる | 固定10質問のうちAI回答で自社名が出るのが1/10 | AI言及 1→3/10 | 2/10 | — | — |
| 11/10 | リスティング広告の予算増 | やらない | 獲得単価が既に目標超え。AEOに時間を回す | — | — | — | — |
| 11/12 | 比較記事の量産 | 保留 | 相方の手順書が無く、品質が担保できない | — | 12/12 | — | — |

**見直し日の目安**：AEO・SEOの施策は効果が出るまで時間がかかるため、8〜12週後に置く。広告・メールなど反応が早いものは2〜4週後。

## 2. KPI定点記録（月1回・月末）

**最初の月（＝改善前）の数字が一番大事。** 今しか取れない。

| 月 | AI検索からの流入 | AI回答での言及（固定10質問中） | 問い合わせ数（うちAI経由） | 商談数（うちAI経由） | 売上への寄与（推定） | メモ |
|---|---|---|---|---|---|---|
| 2026-11（基準） | | /10 | （ ） | （ ） | | |
| 2026-12 | | /10 | （ ） | （ ） | | |

**取り方**
- **AI検索からの流入**：Googleアナリティクスの参照元で chatgpt.com / perplexity.ai / gemini.google.com / copilot.microsoft.com 等を集計
- **AI回答での言及**：狙う質問を10個固定し、毎月同じ質問をChatGPT・Perplexity・Geminiで聞いて、自社名が出た数を数える。質問は途中で変えない
- **商談・売上**：問い合わせ時の流入元を残しておき、AI経由の商談と受注額を追う

## 3. 社長への月次報告（1枚）

月末に30分で作る。**判断・結果・来月の3点だけ。**

```
【◯月 マーケ報告】

■ 今月の判断
・やった：◯◯（理由：◯◯）
・やらなかった：◯◯（理由：◯◯）

■ 結果（基準月との比較）
・AI経由の流入：◯ → ◯
・AI回答での言及：◯/10 → ◯/10
・AI経由の商談：◯件（受注見込み ◯円）

■ 来月やること
・◯◯（狙う数字：◯◯）

■ 社長に決めてほしいこと（あれば）
・◯◯
```

---

## 4. 1年後に使う形

12か月分の判断ログと月次報告が、そのまま業務委託の提案書になる。

> 「この1年で◯件の判断をし、AI経由の商談を◯件→◯件に伸ばした。
> 作業は手順書で相方に移してあるので、この判断を週2日で続けます。」
