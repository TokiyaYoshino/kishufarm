## いま決まっていないこと

**価格の方針**が最大の未決定事項です。第7章の逆算により、現行価格のままでは
半年 +5〜8件という目標がどの手段でも達成できないことが分かっています。
値上げするか、目標を +2〜4件に下げるかの二択で、9月中に決める必要があります
（営業資料に載せる価格がこれで決まるため）。

そのほか、以下は代表からの情報待ちです。

- がめ吉珈琲・ANUHAIR の実契約額（値引きの有無を含む）
- 代表の時間単価 / 月次の Web事業可処分時間
- 営業メンバーの稼働条件（専任か兼務か、時間単価）
- ANUHAIR の公開状況（目標は2026年7月末でした）

## この資料の限界

**一次資料は確認できていません。** 作成時のネットワーク環境で、
e-Stat・厚生労働省・中小企業庁・経済産業省・農林水産省・IT導入補助金事務局の各ドメインに
到達できなかったため、統計値・法令・補助金要件は制作会社・行政書士事務所・業界団体・
業界メディアの解説記事を複数突き合わせて構成しています。

営業トークとして使う分には十分な精度ですが、**投資家や金融機関に提出する段階では、
各文書の「確認状態」に挙げた原典にあたってください。**
