## 社内向け

顧客にお渡しする想定の1枚です。**「使えます」と言い切らないこと。** 採択率は47.2%（第19回）で、約半分は落ちます。

金額・締切・要件は解説記事の突き合わせによるもので、**公募要領の原本は未確認**です。
顧客に提示する前に、最寄りの商工会議所か公募要領で確認してください。特にウェブサイト関連費の上限は
「定額30万円（第20回から）」と「補助金交付申請額の1/4」で情報源の記述が割れています。

---

ホームページの制作に使える制度は、実質ひとつです。ただし段取りと期限があり、順番を間違えると対象外になります。

## 使えるのは、小規模事業者持続化補助金です

商工会議所・商工会を通じて、お店ご自身が申請する制度です。当社の登録などは必要ありません。

| | |
|---|---|
| 補助上限（通常枠） | **50万円** |
| 補助率 | **2/3** |
| うちウェブ関連の上限（税込） | **30万円** |
| 採択率（第19回） | **47.2%** |

> **先にお伝えしておきます。約半分は採択されません。**
> 第19回は16,576件の申請に対し、採択は7,819件でした。
> ですので「補助金で作れます」とはお約束できません。
> *通らなかった場合でも進められるご予算*でお考えいただくのが安全です。申請用のお見積りは、もちろんお出しします。

なお、よくお名前の挙がる**デジタル化・AI導入補助金（旧 IT導入補助金）は使えません。**
広報を目的としたホームページの制作も、ネット販売サイトも補助の対象外になっています。
対象は事前に登録された既製のITツールに限られ、お店ごとにお作りするサイトは該当しません。

## ウェブの費用だけでは、申請できません

この制度は「販路開拓の取り組み全体」への支援なので、他の費用と組み合わせる必要があります。

| 組み合わせる費目 | 具体例 | 上限 |
|----------------|--------|------|
| 広報費 | チラシ、看板、パンフレット、SNS広告、動画制作 | 30万円（税込） |
| 機械装置等費 | 什器、厨房機器、施術用の機材など | — |
| 展示会等出展費 | マルシェ・展示会への出展料 | — |
| その他 | 旅費、開発費、資料購入費など | — |

実際に採択されている組み合わせは、**ウェブサイト＋チラシ**か、**ウェブサイト＋設備**が多いようです。
美容室で「予約機能つきのサイト＋チラシの作成と配布」で採択された例があります。

> **よくある誤解: 予約システムや業務の自動化も、ウェブサイト関連費に入ります。**
> 「サイト＋予約システム」は組み合わせにならず、同じ30万円の枠に2つ並ぶだけです。
> 別の費目、つまり*チラシや什器のような、ウェブ以外のもの*と組んでください。
> また、広報費もウェブサイト関連費と同じく上限30万円（税込）で、こちらも単独では申請できません。

### 金額の例

| 取り組みの内容 | 事業費 | 補助額 | 自己負担 |
|--------------|--------|--------|---------|
| サイト30万円 ＋ チラシ15万円 | 45万円 | 30万円 | 15万円 |
| サイト30万円 ＋ チラシ15万円 ＋ 什器30万円 | 75万円 | 50万円（上限） | 25万円 |

補助率2/3で計算し、補助上限50万円で頭打ちになります。
サイトの費用が30万円を超える場合、超えた分は補助の計算に入らず、そのままご負担いただく形になります。

## いつ、誰が、何をするか

次回（第20回）の締切から逆算した段取りです。**太字の日付は動かせません。**

| 時期 | やること |
|------|---------|
| 10月中 | **商工会議所・商工会にご相談** — お店の所在地の窓口へ。事前予約が必要なことが多いので、早めに。当社は同席できます |
| 11月中 | **当社からお見積り／経営計画書の作成** — お見積りは申請書類の一部になります。経営計画書はお店ご自身で作成し、商工会議所に相談しながら仕上げます |
| **12月4日** | **様式4（事業支援計画書）の発行期限** — 商工会議所が発行する書類です。この日を過ぎると今回は申請できません |
| **12月15日 17:00** | **申請の締切** — 電子申請。第20回の受付開始は11月5日です |
| 審査 | 採択の発表を待ちます。この間は着手できません |
| **交付決定** | **ここではじめて発注できます** — 交付が決まる前の契約・発注・お支払いは、すべて対象外になります |
| 年明け〜 | **制作** — PLAN01で4週間ほど、フルパッケージで8週間ほど |
| 公開後 | **実績報告** — お店ご自身で提出します。当社は必要な資料をご用意します |

> **いちばん多い失敗: 採択されたから大丈夫だと思って、先に制作を始めてしまうこと。**
> 採択と交付決定は別です。交付決定の通知を受け取ってからでないと、その費用は補助の対象になりません。
> 正式なご契約は交付決定後にお願いしています。それまでは*お見積りをお出ししている段階*という扱いです。
