# 見積書と契約条項のひな形

> Artifact: https://claude.ai/code/artifact/47c04701-c6e3-49dc-b96a-a304daf6f88f
> 作成 2026年9月2日 / 社内向け

2社のうちは口頭で回りますが、5社になると決めていない項目が必ず揉めます。
受注が増える前に、いま埋めておくもの。条文はそのまま使える形で書いてあります。

> **これは法務レビューを受けていないドラフトです。**
> 弁護士・行政書士の確認を経ていません。実際に締結する前に、少なくとも一度は専門家に見せてください。
> 特に著作権と契約不適合責任は、書き方ひとつで負担が変わります。
> 条文中の 【 】 は案件ごとに埋める箇所です。**甲＝お客さま、乙＝kishufarm** としています。

## まず1つだけ入れるなら — 汎用コンポーネントの著作権を、当社に留保する

制作物の著作権は、お客さまに移すのが一般的です。それ自体は問題ありません。
問題は**「制作物」に何が含まれるか**で、ここを切らずに全部を渡すと、
案件Aで作った予約カレンダーの部品を案件Bで使えなくなります。
*1件あたり92時間を46時間に減らす計画の前提が、契約で崩れる*ということです。

**効く場面:** 2件目以降。部品を使い回せるかどうかが、ここで決まります。

```
第◯条（著作権）

1. 本件成果物（本件ウェブサイトを構成するデータ、デザイン、文章及び画像をいう。
   以下同じ。）に関する著作権（著作権法第27条及び第28条の権利を含む。）は、
   甲が本件業務の対価の支払を完了した時をもって、乙から甲に移転する。

2. 前項にかかわらず、次の各号に関する著作権は乙に留保される。この場合、乙は甲に対し、
   本件成果物の利用に必要な範囲で、これらを無償かつ期間の定めなく利用することを許諾する。
   ① 乙が本件業務の開始前から有していた著作物
   ② 乙が汎用的に利用する目的で作成した部品（テンプレート、ライブラリ、
      コンポーネント、設定ファイル等をいう。）
   ③ 第三者が提供するソフトウェア及びその利用条件に従って組み込まれた部分

3. 乙は、甲に対し、本件成果物に関する著作者人格権を行使しない。
```

## 残りの5項目

### 検収

**効く場面:** 請求のタイミング。曖昧だと「まだ確認中」で入金が延びます。

```
第◯条（納入及び検収）

1. 乙は、甲に対し、本件成果物を納入する。
2. 甲は、納入後【7】日以内に検査を行い、その結果を乙に通知する。
3. 甲が前項の期間内に通知を行わないときは、当該期間の満了をもって
   検収に合格したものとみなす。
4. 本件ウェブサイトが甲の指示により一般に公開されたときは、
   当該公開の時をもって検収に合格したものとみなす。
```

### 契約不適合責任

**効く場面:** 公開から半年後の「ここが動かない」。期間を切らないと無期限の口約束になります。
相場は小規模なサイトで3ヶ月〜半年、複雑な実装を含むもので1年程度。
**PLAN01は3ヶ月、PLAN02・03は6ヶ月**を基準にします。

```
第◯条（契約不適合責任）

1. 本件成果物が種類、品質又は数量に関して契約の内容に適合しないときは、甲は乙に対し、
   検収に合格した日から【6】か月以内に限り、履行の追完を請求することができる。
2. 前項の期間が経過した後の修正、改修その他の対応は、別途協議のうえ有償とする。
3. 次の各号に起因する不適合について、乙は責任を負わない。
   ① 甲が提供した文章、写真その他の素材
   ② 甲が指定した仕様
   ③ 検収合格後に甲又は第三者が行った変更
   ④ 第三者が提供するサービスの仕様変更又は提供の終了
```

### 再委託

**効く場面:** 外注を使うとき。**この条項が無いと、外部委託そのものが契約違反になります。**
制作キャパシティの打ち手として外注を考えている以上、必須です。

```
第◯条（再委託）

1. 乙は、本件業務の全部又は一部を第三者に再委託することができる。
2. 乙は、再委託先に対し、本契約に基づき乙が負う義務と同等の義務を負わせるものとし、
   再委託先の行為について甲に対し責任を負う。
```

### 契約終了時の引渡し

**効く場面:** 他社に乗り換えられるとき。
**「作って終わりにしない」を売っている以上、辞めるときの綺麗さも商品のうち**です。ここを渋ると評判が落ちます。

```
第◯条（契約終了時の引渡し）

1. 本契約が終了した場合、乙は甲に対し、次の各号を引き渡す。
   ① 本件成果物のソースコード一式
   ② 本件ウェブサイトに係るドメイン及び各種サービスのアカウント管理権限
2. 前項の引渡しは、甲が乙に対する本件業務の対価の支払を完了していることを条件とする。
3. 引渡しに要する作業が通常の範囲を超える場合、乙は甲に対し、
   別途その費用を請求することができる。
```

### 業務の範囲

**効く場面:** 修正が終わらないとき。回数を切らないと、粗利がここで溶けます。

```
第◯条（業務の範囲）

1. 本件業務の範囲は、別紙見積書に記載のとおりとする。
2. デザイン及び構成に関する甲の修正依頼は、各工程につき【2】回までを本件業務に
   含むものとし、これを超える依頼については、乙は別途見積りのうえ対応する。
3. 本件ウェブサイトに掲載する文章、写真その他の素材は、甲が乙の指定する期日までに提供する。
4. 甲は、前項の素材が第三者の権利を侵害しないことを保証し、これに起因して
   紛争が生じた場合は、甲の責任と費用においてこれを解決する。
```

### 掲載内容の責任（医療機関・施術所向け）

**効く場面:** 歯科・接骨院・鍼灸院。医療広告規制は「何人にも適用」されるため、
**この条項があっても制作側の責任が完全に切れるわけではありません。** それでも責任分界を書いておく意味はあります。
歯科を受けるなら、これに加えて限定解除4要件のチェックと、公開前チェックの工数を見積りに含めてください。

```
第◯条（掲載内容に関する責任）

1. 本件ウェブサイトに掲載する内容が、医療法、医薬品医療機器等法、柔道整復師法、
   あん摩マツサージ指圧師、はり師、きゆう師等に関する法律その他の関係法令及び
   ガイドラインに適合することについては、甲が最終的な責任を負う。
2. 乙は、甲に対し、前項の法令等に関する一般的な情報を提供することがあるが、
   これは法律上の助言ではない。
3. 甲は、本件ウェブサイトの公開に先立ち掲載内容を確認し、乙に対して承認の意思表示を行う。
```

## 見積書 — 書式と、決めておく条件

見積書は、補助金を使う場合には申請書類の一部になります。あとから直せません。

| 項目 | 書き方 |
|------|--------|
| 件名 | 「◯◯様 ウェブサイト制作一式」。補助金申請に使う場合は、経営計画書の取り組み名と揃える |
| 内訳 | プラン一括ではなく、**工程で分ける**（設計・デザイン・実装・予約システム・EC・AEO設定）。補助金では「ウェブサイト関連費」と他の費目の切り分けを見られるため、混ざった見積りは通りにくい |
| 金額 | 税抜・消費税・税込を分けて記載。ウェブサイト関連費の上限30万円は**税込**で判定される |
| 有効期限 | 発行日から**1か月**。補助金案件は交付決定まで時間が空くので、**3か月**または「交付決定日から30日」とする |
| 納期 | 「ご発注から◯週間」と書く。**日付で書かない**。素材の提供が遅れると全体がずれるため |
| 支払条件 | 着手金**50%**・検収後**50%**を基準に。全額後払いは、個人店相手では回収リスクが高い |
| 含まないもの | ドメイン代、各サービスの月額、決済手数料（3.0%）、写真撮影、原稿作成。**書いていないと含まれていると思われます** |

### 補助金案件のときだけ、追加する注記

見積書の備考に、次の2行を入れます。顧客が交付決定前に発注してしまう事故を防ぐためです。

```
・本見積書は小規模事業者持続化補助金の申請用です。
・正式なご発注は、交付決定通知の受領後にお願いいたします。
  交付決定前のご発注は補助対象外となります。
```

### 支払条件を50/50にする理由

制作は前工程に工数が寄ります。設計とデザインで全体の半分近くを使うため、
全額後払いにすると、途中で頓挫したときに*作業の半分が丸ごと損失*になります。
着手金を取ることは、顧客側にとっても「本当にやる」という意思決定の区切りになります。
