# 事業の定義 — 誰の、どんな課題を、どう解決するか

> 作成 2026年9月28日 / 対象読者: メンバー全員 / Artifact: なし（この Markdown が正）
> 01〜09 は「何を作るか」から組み立てていた。この章は「店がどこにお金を払っているか」から組み立て直したもの。
> パッケージの中身と月次レポートの指標は、ここから決まる。

## 結論（一文）

> **ポータルに毎月払わないと客が来ない飲食店・美容室に、
> AI検索とGoogleから見つけてもらう入口と、来たお客さんとLINEで直接つながる仕組みを作り、
> 新規を増やしながら、ポータルへの支払いを段階的に減らしていく事業。**

- **今やる理由**: 検索の入口がAIに移りつつある。有料ポータルに寄せていた比重を、AEO・GBP（無料）と自社の資産に移すタイミング
- **店に残る資産は2つ**: 新規が入ってくる入口（AEO・GBP・サイト）と、来た客との関係（LINE友だちリスト）
- **やらないこと**: 「ポータルをやめましょう」とは言わない。新規が減る不安に答えられず、商談が止まる

## 02. 課題を段階で整理する

店を知ってから常連になるまでの流れで、どこにお金が出ていくか。

| 段階 | 今かかっているお金 | あるべき姿 | 当社の打ち手 |
|------|------------------|-----------|-------------|
| **入口（新規集客）** | 掲載料（固定費） | ポータルに払わないと集客が難しいのは事実。**AEO・GBPの比重を上げ、ポータルへの依存を下げる** | AEO、GBP、口コミ、自社サイト |
| **予約** | 1人ごとの手数料、新規クーポン | 手数料とクーポンで利益を削られない | 再来の予約をLINEで自前に受ける |
| **管理（守り）** | 予約台帳、保守 | 最低限の機能で簡単に。無料ツール中心 | GBP・無料の台帳・LINEで組む。**台帳は作らない** |
| **支払い** | 決済手数料 約2.5% | 現金が理想だが現実的でない | **主戦場にしない**。事前決済は無断キャンセル防止の保険として扱う |
| **デリバリー**（飲食） | 売上の12〜35% | 来店してもらう工夫 | **主戦場にしない**。LINEでテイクアウトを受けるくらいまで |
| **EC** | プラットフォーム手数料 | 自分でコントロールできる売上源に | 自社EC。**LINEの友だちリストに売ることで育てる** |

**全段階が「お客さんと直接つながっているか」で決まる。** 再来の予約も、クーポンなしの呼び戻しも、ECの売上も、LINEでつながっていなければ起きない。

## 03. AEOとポータルの関係 — 「使わない」ではなく「比重を移す」

- **AEOの比重は大きくする。** ただし、ポータルのコストを下げるのは**打ち手ではなく結果**。自前の入口から新規が入るようになった分だけ、ポータルのプランを下げられる
- AI検索（GoogleのAI Overviews、ChatGPTなど）がお店を答えるときの情報源は、**食べログ・HPBのページとGoogleマップの口コミ**が多い。AIの時代になっても、すぐにポータルが不要になるわけではない
- GBPもプラットフォームである。正確には「**有料のプラットフォームから、無料のプラットフォーム（Google・LINE・Instagram）と自社の資産に比重を移す**」
- 地域の店のAEOで中核になるのは、**サイトよりもGBPと口コミ**。PLAN03に入っているので強みになる

## 04. 提案の型 — 新規を増やしながら、段階的にコストを下げる

**費用を下げる提案だけでは、店主は動かない。** 各段階で「新規がどう増えるか」をセットで提示する。
コストを下げるのは、新規が自前で入るようになったことを数字で確認してから。

| 段階 | 目安の時期 | 新規を増やす施策 | コストへの効果 | 店主が見る数字 |
|------|-----------|----------------|--------------|--------------|
| **0. 現状把握** | 商談時 | — | — | ポータルの請求書（月額・手数料）、予約経路の内訳 |
| **1. 入口を作る** | 公開〜3ヶ月 | サイト、GBPの整備、構造化データ、口コミ依頼の仕組み | まだ下げない。ポータルは継続 | GBPからの電話・経路検索の数、口コミ数 |
| **2. 来た客とつながる** | 公開直後から | 初回来店時にLINE登録 → お礼と口コミ依頼 → 再来の案内 | 再来の予約の手数料とクーポンが消え始める | LINE友だち数、新規の再来率（美容）、自前経由の予約の割合 |
| **3. 自前の入口から新規が入る** | 3〜6ヶ月 | AEOの引用チェックと修正、口コミの積み増し、ECで常連以外にも接点を作る | 自前の新規が増えた分を確認 | 自前経由の新規数、AI検索での引用状況 |
| **4. ポータルを見直す** | 6ヶ月〜 | ここまでの施策を継続 | **ポータルのプランを1段下げる**（ここで固定費が減る） | ポータルへの月額の支払い |

- 段階1〜2はポータルに一切手を付けないので、**店主にとってリスクがない**。ここが商談を通すための条件
- 段階4の判断材料を毎月出すのが、PLAN03の月額保守の役割になる

## 05. パッケージへの影響

| 変更点 | 理由 |
|--------|------|
| **月次レポートの主な指標を「AI引用の有無」から下の5つに変える** | 店主が知りたいのは「ポータルのプランをいつ下げられるか」 |
| **飲食店向けには予約システムを自作しない**。店が使っている台帳（無料含む）のLINE連携・Googleで予約の設定に留める | 自作の予約カレンダーはポータルと空席を連携できず、二重予約のリスクが上がる（推定・要確認） |
| **美容室向けは「再来率を上げる仕組み」として売る**。PLAN03の来店後LINE配信がこれにあたる | 手数料削減は月1万円前後だが、再来率+10ptは年数十万円規模 |
| PLAN01（HPのみ）は「入口」として残すか判断が要る | 段階2（LINEでつながる）が入らないと、この課題を解決しない |
| 支払い・デリバリーは提案の主軸から外す | 金額が小さい、または当社が変えられない |

### 月次で追う数字

| 指標 | 何がわかるか |
|------|------------|
| 自前経由の予約の割合 | ポータルのプランを下げられるタイミング |
| LINEの友だち数 | 店に残った資産の大きさ |
| 新規客の再来率（美容） | 常連化がうまくいっているか |
| GBPからの電話・経路検索の数 | AEO・GBPの効果（AI経由の流入は直接測りにくいため、その代わり） |
| ポータルに払っている月額 | 最終的に減らしたい数字 |

## 06. 今日やること — 実績で仮説を確かめる

この一文がそのまま営業トークになるかは、**既存2社で数字が動いたか**にかかっている。

**ANUHAIR の店主に聞く**
- [ ] HPBを使っているか。使っているなら月々の支払い（掲載料・手数料）はいくらか
- [ ] 自作の予約カレンダーとSALON BOARDの空き枠を、どうそろえているか
- [ ] 予約の経路の内訳（LINE・サイト・電話・HPB）。公開前と比べて変わったか
- [ ] LINE予約を始めてから、新規客の再来率に変化はあったか

**がめ吉珈琲 の店主に聞く**
- [ ] 食べログ等に掲載しているか。有料プランか、ネット予約を使っているか
- [ ] 月々の支払いはいくらか
- [ ] サイト公開後、Google（GBP）から来た客は増えたか。豆のEC・通販のニーズはあるか

**聞けたら埋めるもの**
- 公開前後の「自前経由の予約の割合」と「ポータルへの支払い」→ 商談資料の実績欄
- 数字が動いていなければ、どの段階で止まっているか（入口か、LINE登録か）を特定する

## 確認状態

- 料金は代理店・業界メディアの記事から取ったもので、**公式の料金表は未確認**。特にHPB・ホットペッパーグルメの有料プランは非公開で地域差がある
- 「ポータルは提携する台帳としか空席を連携できない」「無料台帳の他社連携の範囲」は推定。飲食店の商談前に確認する
- HPBの手数料上限撤廃（2026年1月）は記事1件のみ
- 営業の現場では、店主の**実際の請求書**を見せてもらうのが最も確実
