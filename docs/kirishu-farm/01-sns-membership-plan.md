# 霧珠ファーム SNS×LINE会員 計画

2026-10-11 作成。ぶどうの木会員権を、SNSで知ってもらう → LINEに登録してもらう → LINEで売り切る、の流れで売るための計画。

## 前提

- **全体目標**：2028年10月までに個人の年収1000万円（`TokiyaYoshino/20260407` の `operating-rules.md`）
- **霧珠ファームの持ち分（仮置き・要決定）**：年300万円。会員権を年3万円×100口で、2028年春に売り切る
- **考え方**：作物の需要はほぼ変わらず、作り手は減り続ける。物が減るほど「顔の見える作り手から自分の分を先に確保できる権利」の価値が上がる。会員権はその権利として売る
- **栽培の時間軸**：2026年11月に植え付け。実がつき始めるのは2〜3年目、ワインまでは4〜5年。2028年10月までは収穫前なので、**売上は会員権の前払いだけ**で立てる

### 成功例の深掘り

**ドメーヌ他火は「ゼロから」ではない。** 2022年3月に、40年以上続いた既存のぶどう畑2.4haを借りて引き継いだ。木がすでに実をつける状態だったので、引き継いだ年のぶどうで委託醸造し、約150本を出せた。2023年はべと病で自社栽培分が全滅。2024年のクラウドファンディングは「放棄されそうな畑を救う」という物語で369人を集めた。
→ 苗木から植える霧珠は、収穫まで2〜3年かかる。**早くワインを出すなら、既存の畑を借りるか、ぶどうを買って委託醸造する道がある**（要検討）。

**しあわせスイカ農園の完売までの流れ。** スイカ栽培45年以上のベテラン農家が、2018年ごろに通販を始め、7年かけて今の形にした。
1. 自社の通販サイトを作る（店舗販売はしない）
2. LINE登録の特典を用意する（「スイカがとびきり美味しくなるレシピ集」）
3. 収穫状況をLINEとサイトで伝える
4. **販売開始の日時を事前にLINEで知らせ、一斉に売り出す** → 開始前から400人以上がサイトで待つ → 24分で400玉完売
5. 毎年これを繰り返し、販売数を増やしていく

**林ぶどう園（YouTube）の視聴者は、主に作り手側。** 「ぶどうの学校」「1から育てよう」を掲げ、苗木の植え方などの栽培解説が中心。投稿はほぼ週1本（推測）。人気動画は芽傷処理の解説（約6.7万回）で、栽培したい人・就農を考える人が見ている。本人も「大きくバズった動画はまだない」と話している。消費者向けに近いのは「ぶどうが届くまで」（約3.5万回）。
→ 栽培の技術解説は新規就農コンサルの集客には効くが、会員権の買い手は集まりにくい。会員権向けの発信は「自分の木が育つ物語」「届くまで」に寄せる。

**ファームコネクトのX代行事例（仮説）。** 具体的な施策は有料マニュアルの中で公開されていない。分かっているのは、同じ事例（K農園）で「枝豆 農家直送」「白いとうもろこし 通販」などの検索キーワードでの上位表示も狙っていたこと。
- 仮説1：フォロワー0から翌月に112セットなので、**買った人の多くはXのフォロワーではなく検索から来た**可能性が高い
- 仮説2：1セット約2,700円（30万円÷112）の、迷わず買える価格だった
- 仮説3：白いとうもろこしなど、珍しく旬が短い商品だった
→ 霧珠では、SNSとは別に「ぶどうの木 オーナー」「ワイン オーナー 和歌山」で検索して来る人の受け皿（募集ページ）を作っておく。

**ふるさと納税の手続き。** 返礼品を決めるのは自治体で、事業者は自治体の募集に応募する。
1. 畑のある市町村のふるさと納税担当課に問い合わせ、募集要項をもらう
2. 申請する（事業者の情報、返礼品の内容・価格・写真など。要件は自治体ごとに違う）
3. 自治体が審査する。総務省の**地場産品基準**（区域内で生産されたもの、または区域内で提供される体験など）に合うかを見る。木のオーナー権と収穫物は区域内なので合いやすい。ワインは、原料の主な部分が区域内で採れていれば対象になりうるが、委託醸造先が区域外の場合の扱いは要確認
4. 承認されたら、ポータルサイト（ふるさとチョイス・楽天など）に掲載される
5. 寄付が入ったら事業者が発送する

守るルールは次のとおり。
- **返礼品の価値は寄付額の3割以下**。年3万円の会員権なら寄付額は10万円になる（りんごの木10万円の例と同じ水準）。霧珠に入るのは1口あたり約3万円
- 送料・ポータル手数料を含む経費は寄付額の5割以下
- 2025年10月からポータルのポイント付与が禁止され、地場産品基準も厳しくなっている
- 寄付者の個人情報は自治体が管理するため、LINEに登録してもらえるかは要確認。発送物にLINEのQRを入れる（ミヤハラ農園の方法）で補う
- ワインを送るなら酒類の免許が別に要る
