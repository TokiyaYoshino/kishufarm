## 1. 2制度の位置づけ

| | 小規模事業者持続化補助金〈創業型〉 | 青年等就農資金 |
|---|---|---|
| 性質 | 補助金（返済不要）・補助率2/3 | 融資（要返済）・**無利子** |
| 上限 | 200万円（インボイス特例で+50万円） | 一般3,700万円／特認1億円 |
| 窓口 | 商工会議所＋J-Grants（中小企業庁） | 市町村認定 → 日本政策金融公庫 |
| 使える先 | 販路開拓、加工、直販・体験受入れの設備 | ぶどう生産用の施設・機械、果樹の新植/改植・育成費、資材費 |
| 使えない先 | **農作物の生産自体に必要な経費** | **農地等の取得費**、国の補助金を財源に含む補助事業 |
| 年内の到達点 | **12/15までに申請完了** | 認定申請 →（認定後）公庫へ融資相談 |

**2制度は自然に棲み分く**。持続化の公募要領 p.5 ※3 が「個人農業者であっても、農作物の加工や農作物を用いた料理の提供等を行う事業については、その加工や料理の提供等に必要な経費は、補助対象となります。（**農作物の生産自体に必要な経費は、補助対象外です**）」と定めているため、ぶどう栽培の設備は就農資金、オーナー制度・直販の販路開拓は持続化、という切り分けになる。

⚠️ 青年等就農資金は「国の補助金を財源に含む補助事業」が対象外。**同一の設備を両制度に重複計上しない**ことを両計画書で示すこと（[[keihi-sekisan]] と [[08-nogyo-keiei-keikaku]] の投資計画を並べて確認する）。

- [x] 開業日が 2025/12/15〜2026/12/15 の間 → **2026/7/7**（開業届の「開業・廃業等日」で判定。書類の発行日・提出日ではない）
- [ ] 開業届の控えで**事業所所在地・事業内容の記載**を確認（「亀岡」を実物で確定させる）→ 様式4の管轄商工会議所が決まる

- [ ] 常時使用する従業員数が基準内（商業・サービス業5人以下／製造業その他20人以下。2人体制なのでいずれも可）
- [ ] **系統出荷による収入のみの個人農業者ではない**ことを示せる（野菜卸1〜2件・オーナー制度の直販。示し方は [[hearing-questions]] で事務局に確認）

- [ ] 過去に〈創業型〉で採択され事業を実施していない

### 青年等就農資金

- [x] 原則18歳以上45歳未満 → **中川さんは45歳未満**
- [ ] 農業経営開始から5年以内（開始日を確定させる）

## 3. クリティカルパス — 特定創業支援等事業の証明書

持続化〈創業型〉の成否はここで決まる。公募要領 p.7 ※3：

> 個人事業主本人が、特定創業支援等事業による支援を受けた者であることが要件となります（個人事業主本人以外の者（家族専従者や後継予定者等）が直接支援を受けた場合は対象外です）。

**中川さん本人が受講する必要があり、吉野が代わりに受けることはできない。**

### 亀岡市ルート

| ステップ | 内容 |
|---|---|
| 支援を受ける | 亀岡商工会議所の**起業セミナー**（「経営」「財務」「人材育成」「販路開拓」の4分野すべて修了）、または**創業支援相談を1か月以上にわたり4回以上** |
| 証明書を申請 | 亀岡市商工観光課（市役所3階5番窓口／0771-25-5033）へ 申請書＋受講証明書の写し＋**開業届の写し** を提出 |
| 発行 | **通常1週間程度** |

亀岡市は「事業開始5年未満の個人事業主」を対象とし、証明書の利用に地域制限はない。中川さんは2026/7/7開業なので該当する。

### 居住地と受講場所（2026-10-05時点）

- 中川さんの住まいは**11/25まで千葉 → 11/25から大阪**。畑（事業の実体）は亀岡のまま
- 亀岡市の対象者要件に住所の条件は書かれておらず、事業所も亀岡にあるため、**亀岡ルートを継続**する。公募要領 p.7 ※1 により、支援を受けた地域と創業地が違っても補助対象になる
- 対面のみだと千葉から4回通うのは難しいため、**オンライン受講の可否を中川さんが亀岡商工会議所に確認中**
- **大阪ルートは今回採らない**：大阪産業創造館「チョイス！」創業後コースは大阪市内の住所が条件で会場参加のみ（オンライン配信のセミナーは回数に数えない）。転居後の11/26に始めても、4回目は12/26以降になり12/4に間に合わない
- 亀岡が対面のみの場合の代替は、**千葉の居住市**の特定創業支援（11/25までに4回を終えるため、初回は10/24頃まで）
- 大阪商工会議所への入会は補助金の要件と無関係（任意・販路づくり目的）。様式4の依頼先は事業所の地域＝亀岡商工会議所のまま

- [ ] **8月中に亀岡商工会議所（0771-22-0053）へ電話**し、起業セミナーの開催日程と創業支援相談の枠を確認する
- [ ] セミナーの次回開催が12月以降なら、**創業支援相談（1か月以上・4回以上）に切り替える**
