# 補助対象経費の候補と積算（持続化〈創業型〉第4回）

補助事業の中身が未定なので、**まず候補を洗い出して選べる状態にする**のがこのファイルの役割。金額はすべて**見積り取得前の概算**であり、確定額は `funding/private/` 側で管理する。

前提：補助率 2/3・補助上限200万円。目標は**補助100〜150万円（経費150〜225万円・自己負担50〜75万円）**。

---

## 1. 大前提 — 「農作物の生産自体」は対象外

公募要領 p.5 ※3：

> 個人農業者（林業・水産業者も同様）であっても、農作物の加工や農作物を用いた料理の提供等を行う事業については、その加工や料理の提供等に必要な経費は、補助対象となります。（**農作物の生産自体に必要な経費は、補助対象外です**）

| 入れられる | 入れられない（→ [[08-nogyo-keiei-keikaku]] の就農資金側へ） |
|---|---|
| オーナー制度・直販の販路開拓 | 防除機・剪定機・ぶどう棚・潅水設備 |
| 加工（ジュース等）の設備・試作 | 苗木、肥料、農薬、生産資材 |
| 直販・体験受入れの什器・設備 | 生産用のハウス・倉庫 |
| 販促物・Webサイト・出展 | 農地の取得（就農資金でも対象外） |

---

## 2. 区分別の上限と注意点

| 区分 | 上限 | 注意 |
|---|---|---|
| ①機械装置等費 | — | 汎用品（PC・タブレット）は対象外 |
| ②広報費 | **30万円**（税込・補助金交付申請額の上限） | **単独申請不可**。「単なる会社のPRや営業活動」は対象外 |
| ③ウェブサイト関連費 | **30万円**（税込・補助金交付申請額の上限） | **単独申請不可**。50万円（税抜）以上は処分制限財産 |
| ④展示会等出展費 | — | |
| ⑤旅費 | — | 販路開拓に直接必要なもの |
| ⑥新商品開発費 | — | **テストマーケティングの実施と結果**を補助事業計画に記載すること |
| ⑦資料購入費 | — | |
| ⑧借料 | — | |
| ⑨委託・外注費 | — | Web/システム関連は③へ計上 |
| ⑩設備処分費 | — | |

**共通の対象外**：汎用品（PC・タブレット）、仕入費、人件費、通信費、光熱水費、名刺、金券・商品券、敷金・保証金、**交付決定前の支出**。

**相見積り**：50万円超（税込）の発注は2者以上。中古品は金額を問わず2者以上。

⚠️ **②と③はどちらも単独申請不可**。②+③の2区分だけでも形式上は「ほかの経費と一緒」を満たすが、**①④⑥など第3の区分を必ず入れる**のが安全（かつ②③だけでは補助60万円が天井で目標に届かない）。

## 4. 組み立てパターン（3案）

### 案A：販路開拓に絞る（補助 約100万円）

| 区分 | 経費 | 補助 |
|---|---|---|
| ②広報費 | 45万円 | 30万円 |
| ③ウェブサイト関連費 | 45万円 | 30万円 |
| ①機械装置等費（ショーケース・包装機・体験受入設備） | 45万円 | 30万円 |
| ④展示会等出展費（3回） | 15万円 | 10万円 |
| **合計** | **150万円** | **100万円** |

自己負担50万円。**最も手堅い**。加工品を扱わないため「生産自体」との線引き論争が起きにくい。

### 案B：加工品を含める（補助 約150万円）

| 区分 | 経費 | 補助 |
|---|---|---|
| ②広報費 | 45万円 | 30万円 |
| ③ウェブサイト関連費 | 45万円 | 30万円 |
| ①機械装置等費（加工設備＋直販什器） | 90万円 | 60万円 |
| ⑥新商品開発費（ジュース試作・パッケージ） | 30万円 | 20万円 |
| ④展示会等出展費（3回） | 15万円 | 10万円 |
| **合計** | **225万円** | **150万円** |

自己負担75万円。**加工は公募要領が明示的に認める領域**なので採択根拠は強いが、加工品という新規事業の立ち上げ工数が乗る。[[00-overview]] の週10〜25h配分と衝突しないか要検討。

#### 案A 詳細（たたき台・2026-10-05）

販促の導線「告知（②）→ 申込（③）→ 対面接点（④）→ 受入れ・発送（①）」に沿って並べる。ターゲットは**京阪神（大阪中心）の30〜50代**。中川さんの「大阪で販路を広げたい」は④の出展先と②の広告配信地域で具体化する。金額は概算で、見積り取得後に `funding/private/` で確定する。

| 区分 | 項目 | 概算（税込） | 見積り先候補（2者） | 取得期限 |
|---|---|---|---|---|
| ②広報費 | オーナー制度パンフレット・チラシ（デザイン＋印刷） | 18万円 | 地元デザイン事務所／ネット印刷（ラクスル等）＋デザイン外注 | 10/31 |
| ②広報費 | SNS広告（Instagram／Meta、京阪神30〜50代に配信） | 20万円 | 広告費は実費（見積り不要）。運用を外注する場合のみ2者 | 10/31 |
| ②広報費 | プレスリリース配信 | 5万円 | PR TIMES／@Press | 10/31 |
| ②広報費 | 小計 | **43万円** | | |
| ③Web | オーナー制度の申込LP＋申込フォーム | 25万円 | 制作会社2者（自社内製は人件費扱いで対象外のため外注が前提） | 10/31 |
| ③Web | 会員マイページ（生育レポートの閲覧） | 20万円 | 同上 | 10/31 |
| ③Web | 小計 | **45万円** | | |
| ①機械装置 | 体験受入設備（テント・作業テーブル・椅子・簡易手洗い） | 25万円 | ホームセンター法人窓口／業務用イベント用品店 | 10/31 |
| ①機械装置 | 真空包装機（代理収穫・発送用） | 12万円 | 業務用包装機メーカー2社 | 10/31 |
| ①機械装置 | 小計 | **37万円** | | |
| ④展示会等出展費 | 大阪のマルシェ・物産展 出展料 × 3回 | 15万円 | 出展料は主催者の募集要項で確認（見積り不要） | 10/31（出展候補リストを作る） |
| ④展示会等出展費 | 小計 | **15万円** | | |
| **合計** | | **140万円** | | |

- 補助額の目安：②43万×2/3＝約28.6万（≦30万）、③45万×2/3＝30万（≦30万）、合計140万×2/3＝**約93万円**。自己負担約47万円（ただし**全額140万円を先に立て替える**）
- 50万円超（税込）の発注はないので、相見積りは必須ではない。ただし積算の透明性のため、主要項目は2者から取る
- ⚠️ ③を吉野の内製で作る場合は外注費が発生せず計上できない。**計上するなら外注先に発注**する（自社の人件費は対象外）。内製するなら③を外し、①④を厚くする組み替えを検討する
- 冷蔵ショーケースは外した（直売所を持たないため、発送中心の初年度には優先度が低い）

### 案C：最小構成（補助 約60万円）

②広報費45万＋③ウェブ費45万＝経費90万・補助60万。⚠️ **②③だけの構成は「ほかの経費と一緒に」の要件で不採択リスクがある**ため、少額でも①か④を足すこと。

## 5. 検算ルール

- [ ] 区分別の合計 × 2/3 ＝ 申請補助額（1円未満切り捨て）
- [ ] ②広報費の補助額 ≤ 30万円
- [ ] ③ウェブサイト関連費の補助額 ≤ 30万円
- [ ] ②③以外の区分が最低1つ含まれている
- [ ] 補助額 ≤ 200万円（インボイス特例なしの場合）
- [ ] 50万円超（税込）の発注に相見積り2者以上を取得済み
- [ ] [[08-nogyo-keiei-keikaku]] の投資計画と**重複する設備がない**
