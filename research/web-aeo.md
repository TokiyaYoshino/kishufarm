# HP制作×AEO市場調査

出典: akibare-hp.jp（HP制作費相場）、mieru-ca.com（LLMO/AEO費用相場）（一次〜業界解説記事、直接Fetch）。

## HP制作費用の相場

| 依頼先 | 初期費用 | 月額 |
|---|---|---|
| 自作（DIY） | 0〜20万円 | 数百〜数千円 |
| フリーランス | 10〜50万円 | 1〜3万円（保守込み） |
| Web制作会社 | 50〜300万円以上 | 1〜5万円 |

業種別目安: 士業・治療院・サロン・飲食店 30〜80万円／歯科・建設業 50〜150万円。簡易サイト（3〜5ページ）は10万円以下、集客型コーポレートサイト（10ページ前後）は50〜150万円。

**霧珠ファームの立ち位置**: 個人店舗（カフェ・飲食店・美容室・サロン等）が主対象なら、フリーランス〜小規模制作会社の価格帯（初期10〜50万円、月額1〜3万円）が競合ゾーン。大手制作会社（50〜300万円）とは戦わない。

## AEO/LLMO対策の費用相場

| 料金体系 | 価格帯 |
|---|---|
| スポット診断型 | 初期10〜30万円（単発） |
| 月額伴走型 | 月額10〜50万円 |
| 包括支援型 | 月額50〜100万円以上 |
| 成果報酬型 | 条件次第（リスクあり） |

小規模サイト（30ページ以下）には「スポット診断型」または「月額伴走型（10〜30万円）」が適正とされる。

## 霧珠ファームへの示唆

- HP制作単体（初期30〜80万円）＋AEOスポット診断（10〜30万円）の**セット提案**が、個人店舗向けとして相場に合致し、かつ「制作だけ」の同業他社との差別化になる
- 月額伴走型（10〜30万円/月）は継続収益になるが、週10〜25時間の稼働制約を考えると、まずはスポット診断＋HP制作の単発案件で実績と現金を作り、余力ができたら月額型に広げるのが現実的
- 自社の霧珠ファームHP・kishu-farmアプリの実績自体が「農業×AEO×IT」の営業材料になる（既にeigyo/hp-seisakuスキルで体制あり）
