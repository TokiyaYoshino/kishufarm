# 会員向け販売の目標と週次ルーティン（3人体制）

**目的**: 市場価格より最大30%高い会員価格で売るための発信・声かけを、目標から逆算した**毎週の決まった行動**に落とし込み、3人で回す。
**前提**: 販路の考え方は [[11-vegetable-sales]]。収支の実数は `funding/private/hanro-shushi.xlsx`（公開リポジトリには載せない）。通知と進捗管理は task-reminder シート（[[90day-action-plan]] と同じ運用）。発信の中身と会員フロー図は [[13-sns-content]]。

## 1. なぜ会員は30%高く買うのか（発信で伝えること）

上乗せの根拠を、毎回の発信のどれか1つに必ず入れる。

| 根拠 | 発信の中身 |
|---|---|
| 鮮度 | 収穫した日に発送。市場を通らない |
| 産地と人 | 亀岡の霧（丹波霧）・畑・育てている3人の顔 |
| 限定 | 会員だけの先行予約・数量限定。一般販売より先に案内する |
| 安心 | 栽培記録（農薬・肥料）を公開する（kishu-farm アプリの記録を使う） |
| 関係 | 収穫体験・畑の近況。買う前から畑を知っている状態をつくる |

### 「市場＋30%」は基準として使えるか（[[vegetable-direct-sales]] §2）

**使えない。基準にする市場価格自体が年で±40%動く。** 東京都中央卸売市場のたまねぎ年平均は 2022年175円/kg → 2023年126円 → 2024年147円。相場に30%を上乗せする方式だと、価格が毎年変わって会員に説明できない。

- **会員価格は原価＋利益で先に決め、年間を通して固定する**。「市場＋30%」は結果を測る物差しとしてだけ使う
- 相場が安い年には「スーパーより高い」と言われる前提で、上の5つの根拠を毎回の発信に入れておく
- 固定価格は「常に得」ではなく「相場が安い年に守られる保険」。相場が高い年は取りこぼすことを受け入れる

## 2. 目標（逆算）

### 玉ねぎ（2027年5〜6月に販売）
- 会員に売る量：MINの見込み数量の半分（50%は仮置き）
- 1注文を5kg箱（約20個）・1人平均1.5箱とすると、**購入者は約250人**必要
- LINE登録者のうち購入するのが3〜5割とすると、**2027年4月末までにLINE登録500人**が目標

### ブドウ（2029年ごろ初収穫）
- 3万房を会員に売るには、1人5房でも**約6,000人**の購入者が必要になる。玉ねぎの約25倍の規模
- 玉ねぎの販売を、ブドウの会員リスト作りの1年目として位置づける。3年間でLINE登録を積み上げる
- ぶどうの木会員権（[[01-vineyard]]）と同じお客さんを数えないよう、分け方は別途決める

### 毎週見る数字（task-reminder シートの「毎週見る数字」に入れる）

| 数字 | 目標値 | 意味 |
|---|---|---|
| LINE登録数（累計） | 500（2027/4末） | 結果に一番近い数字 |
| 発信の本数（今週） | 4 | SNS 3本＋LINE配信1本 |
| 声をかけた人・店の数（今週） | 10 | 対面・紹介・飲食店など、外に出た行動 |

月に1回、LINE登録数が目標ペース（月に約80人増）に届いているかを定例で確認する。

## 3. 3人の役割（仮）

| 役割 | 担当（仮） | 持つもの |
|---|---|---|
| 発信・会員設計 | 吉野 | LINE配信の文面、SNSの投稿、数字の集計、予約の仕組み |
| 生産・顧客対応 | 中川 | 畑の近況のネタ出し、問い合わせの返信、卸先・知人への声かけ |
| 撮影・出荷 | いぶき | 畑の写真・動画の撮影、収穫期の箱詰め・発送 |

※ 3人目と担当の割り振りは仮。確定したら書き換える。

## 4. ルーティン

### 毎日（各5分）
- いぶき：畑の写真か動画を1本撮って、共有フォルダに入れる
- 中川：LINEの問い合わせに返信する

### 毎週
| 曜日 | 担当 | やること |
|---|---|---|
| 月 | 吉野 | 先週撮った素材から、今週の投稿3本とLINE配信1本の中身を決める |
| 火・木・土 | 吉野 | SNSに1本ずつ投稿する（1章の根拠を1つ入れる） |
| 水 | 吉野 | LINE配信を1本送る（オフシーズンは隔週でよい） |
| 週のどこか | 中川・いぶき | 声かけを合計10件（知人・マルシェ・飲食店・収穫体験の案内） |
| 金 | 吉野 | LINE登録数・発信本数・声かけ数をシートに更新する |
| 土 | 3人 | 定例30分：数字の確認・遅れの相談・来週の外に出る行動を1件決める |

### 毎月
- 吉野：LINE配信の反応（開封・クリック・返信）を見て、反応がよかった根拠を翌月に増やす
- 中川：会員だけの企画を1つ決める（先行予約・収穫体験・規格外のお試しなど）
- 吉野：noteを1本書く（[[07-note]]）

### 季節の流れ（玉ねぎ）
| 時期 | 重点 |
|---|---|
| 2026年10〜12月 | LINE開設・登録を集める・ふるさと納税の登録 |
| 2027年1〜3月 | 予約の案内（会員に先行案内 → 一般へ） |
| 2027年4月 | 予約締め・発送の段取り |
| 2027年5〜6月 | 収穫・発送・購入者の感想を集める（次の発信の素材にする） |
| 2027年7月〜 | 振り返り → 次の作物・ブドウに向けたリスト作りを続ける |

## 5. 運用ルール
- 毎週の行動は task-reminder シートに「その日のうちに終わる大きさ」で入れる。毎朝の通知で遅れが分かる
- 発信が止まった週は、定例で理由だけ確認する（責めない。素材が足りない・時間がない、のどちらかを解消する）
- 数字は「LINE登録数」を最優先で見る。発信本数・声かけ数は、それを増やすための行動の数
