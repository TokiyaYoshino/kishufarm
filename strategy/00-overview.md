# 全体戦略 — 4事業の役割とリソース配分

## 前提（decision-logより）

- 2人体制（中川: 栽培担当／吉野: 事業開発・Web・IT担当）
- 吉野の稼働: 週10〜25時間
- 全体売上: 年100万円未満（立ち上げ期）
- ぶどうの木: 100本以上（供給は十分）
- 会員権先行登録: **ゼロ**（11月募集開始まで約4ヶ月）
- 野菜卸先: 1〜2件

## 4事業の役割定義

売上がまだ小さい立ち上げ期であること、そして**会員権の先行登録がゼロで11月ローンチが目前**であることを踏まえ、4事業に明確な役割を与える。「均等にやる」のではなく、**時間軸で役割を分ける**。

| 事業 | 役割 | 今90日での位置づけ |
|---|---|---|
| ④ Web制作・AEO | **現金エンジン** | 最優先。既存の営業スキル（eigyo/hp-seisaku）を使い即座に売上を作る |
| ① ぶどうの木会員権 | **ブランド資産・将来の利益率** | 最優先。11月ローンチ直前のため、集客の仕組みを今すぐ作らないと空振りする |
| ② 野菜生産・卸 | **現状維持・信頼基盤** | 中川さん主導。吉野の新規投資は最小限、ただし信頼性訴求の種まきはする |
| ③ 農業管理アプリ | **長期資産（種まきのみ）** | 外部提供は着手しない。実績・実例を集める段階に留める |

**根拠**: research/agritech.md の通り、アプリ市場は無料〜3.3万円で既に埋まっており今は勝負どころではない。research/kameoka-market.md の通り、直売所（JA系）との正面競合は不利で野菜卸の新規拡大には裏付けとなる情報が薄い。一方 research/owner-seido.md は「需要は価格帯を問わず供給を上回りやすい」ことを示しており、**先行登録ゼロという現状が最大のリスク**であることが裏付けられた。Web/AEO事業は既に営業体制（スキル）があり、即金化できる唯一の事業。

## 事業間の相乗効果マップ

```
Web/AEO事業の制作スキル ──→ 会員権の先行登録LP・集客導線を内製
      │
      └──→ 霧珠ファーム自体の実績（HP・会員権・アプリ）が
            Web/AEO営業の「実例」として使える（自社実践ノウハウの訴求）

kishu-farmアプリの栽培記録 ──→ 野菜卸の信頼性訴求（トレーサビリティ開示）
                            ──→ 会員権の「生育レポート」機能にも転用可能

会員権のブランドストーリー（丹波霧） ──→ 野菜卸の差別化訴求にも使える
                                    ──→ Web/AEO営業時の「地域密着の実例」にもなる
```

**中心にあるのは吉野さん自身のスキル**（制作・マーケ・IT）。1つ作ったものを他の3事業に使い回すことで、限られた週10〜25時間の生産性を上げる。

## 週次時間配分の基本方針

| 配分 | 用途 |
|---|---|
| 約40% | 会員権: 先行登録の集客導線構築・集客活動 |
| 約40% | Web/AEO: 営業・受注・制作（現金化） |
| 約20% | 野菜卸・アプリの種まき（トレーサビリティ発信、実績集め） |

週10hの場合: 会員権4h／Web/AEO4h／種まき2h。週25hの場合: 会員権10h／Web/AEO10h／種まき5h、という比率で伸縮させる。

## この戦略で「やらないこと」（90日間）

- アプリの外部提供の本格着手（β打診程度に留める）
- 野菜卸の新規開拓への大きな投資（中川さんの手が空いた時のみ）
- 月額型AEO契約の新規営業（まずはスポット診断＋HP制作で実績作り。research/web-aeo.md参照）
