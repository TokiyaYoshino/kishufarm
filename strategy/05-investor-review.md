# 投資家レビュー — 漏れの指摘と実現可能性の検証

2026-07-18 実施。スタンス:「味方だが財布は他人」。既存戦略（00〜04・90day-action-plan）を出資判断のつもりで詰めた結果。

## 1. ファネルの数理 — 「先行登録20件」は本当に届くのか

90日プランの目標「先行登録20件」を獲得チャネル別に分解すると:

| チャネル | 期待値 | 根拠 |
|---|---|---|
| 知人5人への直接アプローチ | 3〜4件 | 関係性があるため高転換（60〜80%） |
| 知人からの紹介 | 2〜3件 | 紹介依頼を明示的に行った場合 |
| SNS発信（ゼロから3ヶ月） | 1〜3件 | フォロワー数百人到達が精一杯。転換は数% |
| 既存HPのオーガニック流入 | 0〜1件 | 新規ドメインの検索流入が立ち上がるには3ヶ月では不足 |
| メディア取材（当たれば） | 0〜10件 | 不確実。期待値に織り込まない（01-vineyardの方針通り） |
| **合計期待値** | **6〜11件** | |

**結論: 現行チャネルだけでは20件に届かない可能性が高い（期待値の中央値は目標の半分）。**

### ギャップを埋める追加チャネル（優先順）

1. **マルシェ・イベント出店**（亀岡・京都のファーマーズマーケット等）: 対面で「畑の人」から聞く体験はオーナー制度と親和性が最も高い。1回の出店で見込み客と数十人接触できる。**90日プランに追加すべき**
2. **少額SNS広告**（Instagram、月1〜2万円）: 京都・大阪の30〜50代をターゲットに先行案内LPへ誘導。効果測定して転換しなければ即停止
3. **卸先・Web営業先への同時案内**: どうせ会う相手に会員権の話も1分だけする（追加工数ゼロ）

## 2. 漏れの指摘（既存戦略にない論点）

### 法務・規制（重要度: 高）

- **酒類販売免許が未取得**（HPに「手続き中」と明記）。会員権特典の「ワインの優先案内・会員価格」は免許取得が前提。**取得時期の見込みを確認し、11月募集時の特典表記は「免許取得を条件とする」形に整理しておく**。取得が遅れた場合のプランBがない
- **会員権の法的整理が未着手**: 年会費の前受け（最大100本×10万円=1,000万円規模になり得る）は、返金条件・中途解約・不作時対応を定めた**会員規約**が必須。FAQに「不作の年の対応は募集要項で明示します」とあるが、その募集要項がまだない。11月に間に合わせるには9月中にドラフトが必要
- **収穫体験の保険**: 畑での怪我に備えるレクリエーション保険等（年数千〜数万円）。募集開始前に加入
- **特定商取引法に基づく表記・プライバシーポリシー**: オンラインで申込を受けるなら必須。現行サイトには見当たらない

### キャッシュフロー（重要度: 高）

- 会員権の入金は**11月以降**。90日間（7〜10月）に新規の現金を生むのはWeb/AEOだけ。Web/AEO初受注が遅れると、この期間の追加収入はゼロになる
- 対策: Web/AEOの初案件は**単価を下げてでも早く取る**（下記3参照）

### オペレーション（重要度: 中）

- **生育レポートの運用負荷**: 会員30人に月1回のレポートを個別に作るのは破綻する。テンプレート＋一斉配信（メール/LINE公式）の仕組みを募集開始前に用意。kishu-farmアプリの記録を流用できれば工数を大幅圧縮できる（相乗効果マップの具体化）
- **決済手段**: 銀行振込のみだと転換率が落ちる。Stripe等のオンライン決済を検討（手数料3.6%は許容範囲）
- **会員管理**: 初年度はスプレッドシートで十分。システム化しない（時間を守る）

### 事業リスク（重要度: 中）

- **単一障害点が2つ**: 栽培は中川さん1人、それ以外は吉野さん1人。どちらかが倒れると全事業が停止する。90日で解決不要だが、認識だけは共有しておく
- **天候リスク**: 2026年の作柄が悪いと初年度オーナーの体験が毀損し、**2年目の更新率が崩れる**。会員権はLTV商売（更新されて初めて利益が出る）。不作年の代替特典（野菜セット等）を規約に先に入れておくのはリスクヘッジとして正しい
- **更新率目標が未設定**: 初年度会員の翌年更新率70%以上を暗黙の成功基準として置くべき。更新率が50%を切る商品設計なら毎年新規集客に追われ、スケールしない

## 3. 実現可能性の検証（事業別）

### ①会員権 — 条件付きで実現可能

- 供給100本・価格3〜10万円は市場実例と整合（research/owner-seido.md）
- ただし目標20件はチャネル追加（上記1）が前提。**追加しなければ10件前後で着地する可能性が高い**
- 法務準備（規約・保険・特商法表記）を9月中に終えないと、集客に成功しても11月に募集を開けられない。**集客と同じくらい「募集を開ける準備」がクリティカルパス**

### ④Web/AEO — 実現可能だが単価想定を修正

- 04-web-aeo.mdの単価想定（HP制作30〜80万円）は**実績が積み上がった後の相場**。納品実績が自社サイトのみの現状では、初案件からこの単価は難しい
- 修正: **初回1〜2件は10〜30万円の「実績づくり価格」で受け、事例化してから相場価格に上げる**。90日での成約1件は現実的、2件はストレッチ目標
- 接触量の目安: 週2〜3件×12週=約30件接触 → 商談3〜5件 → 成約1〜2件（個人店舗向け営業の一般的な歩留まり）

### ②野菜卸・③アプリ — 「維持・種まき」の判断は妥当

- 市場規模分析（research/market-size.md）でも裏付け: 野菜卸は供給制約型（市場より中川さんのキャパが上限）、アプリは成長市場だが寡占進行中で後発の勝ち筋が現状ない
