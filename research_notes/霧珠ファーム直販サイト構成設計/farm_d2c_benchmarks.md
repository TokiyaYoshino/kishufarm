# 農家直販(D2C)サイトの構成・デザインと会員/オーナー制度のベンチマーク(2026年11月調査)

> 調査上の制約(重要):このセッションでは外部サイトの直接取得(WebFetch)がネットワーク許可外で全て失敗した(thebase.com / stores.fun / www.shopify.com / shop-pro.jp)。以下は全て **Web検索結果の要約・抜粋** に基づく。各農園サイトのトップページ実物や、各プラットフォームの公式料金ページは目視確認できていない。料金は二次情報が多く、採用前に公式ページでの再確認が必要。出典に無い事柄は「Gaps」に回した。

## 1. 評価の高い小規模農家直販サイトのページ構成とトップページの並び(具体例)

### Takeaway
和歌山の柑橘系で直販が確立している農園(早和果樹園・伊藤農園・観音山フルーツガーデン)は、いずれも「公式通販サイト」を軸に、定期便/頒布会を独立カテゴリとして持ち、無料会員登録+ポイントを組み合わせている。トップページの具体的なセクション順は今回実物を取得できず未確認。

### Cited Findings
和歌山・柑橘/梅の例
- 早和果樹園(有田みかん)は自社ドメインで「公式通販サイト」を運営し、URL構造上 `/c/subscription/` という定期購入・頒布会カテゴリを持つ。会員は年会費無料、新規登録で100ポイント付与 — [早和果樹園 公式通販](https://sowakajuen.com/) / [旬のみかんお楽しみ定期便](https://sowakajuen.com/c/subscription/items_050-010)
- 早和果樹園は公式LINEアカウント(本社店)も運用している — [LINE公式](https://page.line.me/jkm5995r)
- 伊藤農園(有田)は「定期便」を専用カテゴリ(`/c/teiki_group`)にまとめ、生果とジュースの定期便を分けて掲載。訴求は「ノーワックス・ノーブラッシングで安心・安全」「スキップ・解約もかんたん」「定期購入なら毎月お得」。会員価格の表示あり — [伊藤農園 定期便](https://www.ito-noen.com/c/teiki_group) / [フルーツ定期便](https://www.ito-noen.com/c/orange/teiki/hp-large) / [みかんの定期便](https://www.ito-noen.com/c/orange/teiki)
- 観音山フルーツガーデン(紀の川市)は「ご利用案内」ページを独立させ、会員登録でポイント付与、決済ページでお届けサイクルを指定可能。通常商品も備考欄で定期便希望を受け付ける — [ご利用案内](https://www.kannonyama.com/view/guide) / [すべての商品](https://www.kannonyama.com/view/category/all_items)
- 深見梅店(上富田町)は自社農園で南高梅を有機栽培、農園・加工施設とも有機JAS認証を取得し自社サイト yasashi-umeya.jp を持つ(検索結果の要約による。定期便は確認できず) — [和歌山県資料](https://www.pref.wakayama.lg.jp/prefg/071700/d00209446_d/fil/2023-4.pdf)
- みなべ町の梅農家(硲さん)は梅干し・梅酒を製造し umeyoshi.com を運営 — [近畿農政局 和歌山農業女子紹介](https://www.maff.go.jp/kinki/tiiki/wakayama/wakayamanougyojoshi/shokai/member_hazama.pdf)
- みかんのみっちゃん農園(有田川町、6代目、年間60種類以上・150トン以上の柑橘)は自社直販に加え Makuake とふるさと納税を販路にしている — [Makuake](https://www.makuake.com/project/mitchan-farm/)
- Mikan Mania(有田)は複数農家の柑橘を毎月届ける食べ比べ定期便を Makuake で先行予約販売(最大82種→のち最大162種) — [Makuake](https://www.makuake.com/project/mikan_mania02/)

他地域の例(制作会社まとめ記事経由)
- 寺坂農園(北海道・メロン):トップページで「注文できる商品とお届け時期」がひと目でわかる設計、EC内蔵、LINE問い合わせ対応 — [biz.ne.jp まとめ](https://biz.ne.jp/matome/2003408/)
- 永島農園(神奈川):毛筆ロゴとモノクロ写真で農家の歴史を表現し、下部に「農園紹介/直売所/オンラインショップ」への導線を並べる — [biz.ne.jp まとめ](https://biz.ne.jp/matome/2003408/)
- おだやか家(相模原):白基調で無添加・有機らしいシンプルさを表現、レスポンシブ対応 — [biz.ne.jp まとめ](https://biz.ne.jp/matome/2003408/)

ページ要素
- 農研機構(旧東北農研)の資料は、Web産直サイトの構成要素として注文方法・Q&A・特商法表示・掲示板と並べて「お客様の声」を挙げ、消費者の感想を改善・商品づくりに戻す「農家と消費者で創り育てるHP」を方向性として示している(資料は古い) — [NARO資料](https://www.naro.go.jp/org/tarc/to-noken/DB/DATA/056/056-281.pdf)

### Inferences
- 和歌山の先行3園に共通する骨格は「商品カテゴリ/定期便(独立カテゴリ)/ご利用案内/会員登録(無料・ポイント)/LINE」。霧珠ファームでも「定期便・会員」をグローバルナビの独立項目にするのが標準に沿う。
- 寺坂農園の「今注文できるもの+届く時期」をトップ最上部に置く設計は、収穫期が短い梅・柑橘に特に合う(旬カレンダー/予約受付状況の表示)。
- 自社サイトだけで完結させず、Makuake・ふるさと納税・LINEを集客/予約の入口として併用するのが有田の農家の実態。

### Gaps
- 各サイトのトップページの実際のセクション順(ヒーロー→こだわり→商品→声…)は、サイト取得不可のため未確認。一般論を書くことはできるが出典が無いので記載しない。
- 「こだわり/ストーリー」「農園だより(ブログ)」「FAQ」「特商法表記」ページの各園での有無・作りは未確認。
- 上記以外の候補(善兵衛農園、蔵光農園、高田果園など)は調査できていない。例は約10件挙げたが、うち実質的な内容が取れたのは和歌山3園+制作会社まとめの3園。

## 2. 会員権・木のオーナー制度・定期便の設計(階層・価格・特典・申込フロー)

### Takeaway
果樹オーナー制度の相場は1樹あたり年2.5万〜3.1万円前後、募集は数十本の少数限定・期間限定・先着順・前払い・途中解約不可が定型。定期便は1回4,000円台、または年10回一括前払いで割引・送料無料という形がある。多段階の「会員権ティア」を掲げる個人農園の実例は見つけられなかった。

### Cited Findings
オーナー制度
- 秋津野ガルテン(和歌山県田辺市上秋津)みかんの樹オーナー:年間1樹31,000円(契約時払い)、募集30本、募集期間8月10日〜9月末予定(定数で終了)、品種は早生温州(宮川早生)、11月中旬〜下旬のいずれか1日に一度に収穫、契約は収穫までで途中解約・返金不可。樹は地元農家の所有で管理はスタッフ/園主、オーナー名のネームプレートを付ける。申込は募集要項を印刷してFAX/郵送、または問い合わせフォーム。旧年度は収穫時宿泊の1割引特典あり(2026年度の有無は未確認) — [秋津野ガルテン みかんオーナー制度](https://www.agarten.jp/abou/owner-2/) / [オーナー案内](https://agarten.jp/owner/)
- ファミリーツリー(浜松・みかん):1本25,000円。特典は農業体験・収穫体験、自分の木のみかん(最低保証20kg+ジュース)、毎月の農家レポート、月1回の農園見学(予約制)、配送サービス(2020年開始時の情報) — [リセマム(PR TIMES)](https://resemom.jp/release/prtimes/20200709/63788.html)
- あづみ野フルーツらんど(りんご):木1本につき50kg保証(1.4万円オーナーは25kg保証)という収量保証付き2段階。申込はメールフォーム、支払いは銀行振込で入金確認メールなし(ページは古い可能性) — [りんごの木のオーナー募集](https://azuminofl.com/owner/appleowner.html)
- 萬秀フルーツ(愛知・中晩柑/国産グレープフルーツ):既存オーナーで満席のため2026年度(中晩柑は2027年度も)新規募集なし。クレジット決済用の専用ページを持つ — [中晩柑オーナー制度](https://grapefruit.co.jp/owner/orange) / [クレジット決済](https://grapefruit.co.jp/owner/owner_card)
- 土佐文旦の木オーナー制度(buntan.com)は通販カート内の商品として年度ごとに販売、締切日(5/20)を明示 — [buntan.com](https://buntan.com/c/orner/ORNER-BUNTAN)
- 長野県松川町の果樹オーナー制度はクレジットカード/コンビニ/銀行振込を選べる通販形式で申込 — [dansuki.jp](https://dansuki.jp/column/column1489/)
- UMEMARU FARM(小田原)は「みかんの木1本の収穫体験(100kg以上収穫できる木)」をふるさと納税返礼品にしている。収穫は11月後半〜12月後半、1週間前までに予約 — [ふるさとチョイス](https://www.furusato-tax.jp/product/detail/14206/5844455)

定期便・頒布会
- 早和果樹園「旬のみかんお楽しみ定期便」:1回あたり4,680円(税込)。加工品は毎月1日着、生果は完熟期に届く。退会・休止は前月20日までにメールか電話 — [早和果樹園](https://sowakajuen.com/c/subscription/items_050-010)
- 観音山フルーツガーデン「旬宴」:年10回(月1回)の頒布会、支払いは最初に一括。一括前払いで毎回割引+送料無料、最大5,510円お得と表示 — [旬宴](https://kannonyama.com/shopdetail/036000000007)
- 伊藤農園:送料無料の「みかん・柑橘の定期便(レギュラーコース)」など、サイズ別コース。スキップ・解約が簡単であることを訴求 — [伊藤農園](https://www.ito-noen.com/c/orange/teiki/hp-large)

関係人口型
- みなべ町「梅収穫ワーケーション」:2022年開始、延べ1,260名参加、2026年は約17軒の梅農家が受け入れ、5/1〜7/9開催、参加費無料(交通・宿泊・食費は自己負担) — [トラベルボイス](https://www.travelvoice.jp/workation/20260531-20471/)

### Inferences
- 定型の構成要素は「1口(1樹)いくら/募集数/募集期間/収穫日/収量保証またはお届け量/名札/解約不可/申込方法」。会員ページもこの順で書けば他園と比較されやすい。
- 人気制度は既存オーナーの継続で満席になる(萬秀フルーツ)。少数限定+継続優先はファン化の仕組みとして機能している。
- 申込は紙/FAX/フォーム+振込(旧来型)と、カート商品化して決済まで完結(buntan.com、松川町、萬秀)の2系統。後者なら既存のECカートをそのまま会員申込に流用でき、専用の会員システムは不要。
- 梅は「オーナー制度」より「収穫体験・ワーケーション」での関与事例が地元に既にあり、霧珠ファームの会員特典(収穫参加)の参考になる。

### Gaps
- 梅の木オーナー制度の実例(みなべ・田辺)は検索で見つからなかった。
- 複数ティア(例:ライト/スタンダード/プレミアム)の農園会員権、ファンクラブ、CSAの日本での具体例・価格は見つけられなかった。
- 伊藤農園の定期便の正確な価格、各制度の会員LPのレイアウト(実画面)は未確認。
- ファミリーツリーとあづみ野の情報は古く、現行条件は不明。

## 3. ECプラットフォーム(BASE / STORES / Shopify / カラーミー / 食べチョク / ポケマル)の手数料とトレードオフ

### Takeaway
月額0円で始めるなら BASE(実質6.6%+40円)か STORES フリー(5.5%〜)、月商が増えたら STORES スタンダード(月3,300円・3.6%〜)やカラーミー レギュラー(月4,950円・3.4%〜)、Shopify。産直マーケットプレイスは約20%前後と高いが集客付き。数値はほぼ二次情報で、情報源間に食い違いがある。

### Cited Findings
- BASE スタンダード:初期・月額0円、決済手数料3.6%+40円+サービス利用料3%(売れた時のみ) — [imitsu](https://saas.imitsu.jp/cate-ec-cart/service/6373/price) / [stock-sun(2026年6月時点)](https://stock-sun.com/?p=105232)
- BASE グロース:決済手数料2.9%、サービス利用料0円。月額は「月払い19,980円/年払い月16,580円」とする記事と、2022年開始時の「5,980円」とする記事があり食い違う(改定があった模様、公式で要確認) — [stockcrew](https://stockcrew.co.jp/insights/base-fee-how-much); 相違 [ECのミカタ(2022)](https://ecnomikata.com/ecnews/34608/)
- BASE の「定期便 App」は App 自体は無料で、販売時にプラン通りの手数料がかかる — [BASE U](https://baseu.jp/7459)
- STORES:2026年3月24日のプラン刷新で、フリー(月0円・決済手数料5.5%〜)とスタンダード(月3,300円税込・3.6%〜)の二択になったとされる — [stock-sun](https://stock-sun.com/?p=105232)。なお別記事の「1.98%〜/2.48%〜」は対面決済(STORES 決済)の料率で、ネットショップとは別 — [atsoho](https://atsoho.com/apps/p/stores)
- 3,000円の商品1件の手数料試算:BASE 約7.9%、STORES フリー 約6.5%、Shopify ベーシック 約3.4%(月額別) — [stock-sun](https://stock-sun.com/?p=105232)
- カラーミーショップ:フリー月0円、レギュラー月4,950円、ラージ9,595円、プレミアム35,640円(税込、比較サイトの確認日2026-07-28)。決済手数料はフリー6.6%+30円〜、レギュラー3.4%〜 — [atsoho](https://atsoho.com/apps/p/colorme-shop) / [ITreview](https://www.itreview.jp/products/color-me-shop/price)
- Shopify:5種類のプランがあり上位ほど月額が上がり手数料が下がる。2026年8月時点の記事に「月額3,650円」「44,000円」の記載があるが、どのプランかは抜粋から特定できず — [issoh](https://www.issoh.co.jp/column/details/17108/)
- 食べチョク:販売手数料は商品価格(送料を除く)の19.7%。初期登録・月額・決済手数料・振込手数料は無料 — [食べチョク生産者ヘルプ](https://tabechoku-seisansya.zendesk.com/hc/ja/articles/5130126872350-%E8%B2%A9%E5%A3%B2%E6%89%8B%E6%95%B0%E6%96%99%E3%81%AF%E4%BD%95-%E3%81%A7%E3%81%99%E3%81%8B) / [生産者募集LP](https://www.tabechoku.com/lp/farmer/)
- ポケットマルシェ:販売手数料23%・月額0円(比較記事1本のみ、公式未確認) — [takaguchidesign](https://takaguchidesign.com/wp/platform-hikaku)。同記事は産直系は手数料が高めで入金サイクルがやや遅い点を注意点に挙げる
- ポケマルは生産者ごとのコミュニティ機能(投稿・やり取り)が強みと農水省資料で紹介されている — [MAFF資料](https://www.maff.go.jp/j/seisan/kankyo/yuuki/r7_iken/attach/pdf/251009-6.pdf)
- 一般論として、小規模・副業は無料型(BASE/STORES)で始め、規模拡大で有料型へ移る流れが多い — [お名前.com](https://www.onamae.com/column/netshop/8/)

### Inferences
- 月商10万円以下が見込まれる立ち上げ期は固定費0円型が合理的。STORES スタンダードとフリーの差(約1.9ポイント)は月商約17万円で月額3,300円を回収する計算(3,300÷0.019)。
- マーケットプレイス(約20%)は「新規客の獲得費」と割り切り、同梱物やLINEで自社サイト・会員へ誘導する二段構えが有田の農家の販路併用(1章)と整合する。
- 既存の Next.js/Vercel サイトとは「商品ページ・カートへのリンク(別ドメイン/サブドメイン)」で繋ぐのが最も確実。埋め込み可否は下記の通り未検証。

### Gaps
- 公式料金ページを1つも取得できなかった(食べチョクのみ公式ヘルプが検索に出た)。全料金は採用前に公式確認が必要。
- 外部サイトへの埋め込み機能(Shopify の Buy Button / Storefront API、BASE・STORES の商品埋め込み)の現行の可否と条件は確認できなかった。
- BASE のメンバーシップ/コミュニティ系 App、STORES の定期便・会員機能、カラーミーの定期購入オプションの有無と料金は確認できなかった。
- Shopify の日本円でのプラン別月額・国内カード決済手数料、Starter プランの現況は未確認。
- 振込手数料・入金サイクルの比較は未調査。

## 4. コンバージョンに効くデザイン特性とデータ

### Takeaway
農家D2Cに限った公開の転換率データは見つからなかった。確認できたのは、食品メーカー自社ECでの「レビュー閲覧者のCVRが高い」事例と、産直ECでの「生育写真を予約客に共有して不安を減らす」運用事例、および制作会社による定性的なデザイン評価のみ。

### Cited Findings
- 石井食品の自社EC:レビュー施策で月間レビュー投稿数が前年同月比16.2倍、商品詳細でレビューを閲覧したユーザーのCVRは非閲覧者より120%アップ(食品メーカーの事例) — [ネットショップ担当者フォーラム](https://netshop.impress.co.jp/node/14441)
- ナルミヤ・インターナショナル:レビュー閲覧後の購入CVRが2.6倍(アパレルの事例) — [ネットショップ担当者フォーラム](https://netshop.impress.co.jp/node/14563)
- 産直EC「おいしいねいばらき」:運営者が生産者と作物別のLINEグループを作り、生育状況の写真を受け取って予約客に共有。収穫遅れも早めに連絡し顧客の不安を減らしている(数値なし) — [ネットショップ担当者フォーラム](https://netshop.impress.co.jp/node/5842)
- デザイン面の定性評価:白基調でシンプルに(おだやか家)、毛筆ロゴ+モノクロ写真で歴史を表現(永島農園)、トップで商品とお届け時期をひと目で(寺坂農園)。「商品の売りをいかに伝えるか」が重要とされる — [biz.ne.jp まとめ](https://biz.ne.jp/matome/2003408/)
- 食べチョクの実質手数料は顧客支払額比で約8〜18%(2021年5〜7月実績)との公式由来の記載があり、送料込み表示か否かで見え方が変わる — [mietv 解説](https://www.mietv.com/agriculture/tabechoku-listing-guide/)
- 日本郵便のコラムは、農家の直接EC販売の利点として中間マージン削減・販路拡大・消費者の反応を直接得られる点を挙げる — [日本郵便](https://www.post.japanpost.jp/bizpost/column/sales_promotion42/agriculture-ec)

### Inferences
- レビュー/お客様の声を商品詳細ページ内に置く根拠は他業種データで補強できるが、農家サイトでの効果量は不明。
- 予約販売・定期便・オーナー制度のように「払ってから届くまでが長い」商品では、生育写真の定期共有(農園だより、LINE)が不安解消と継続の両方に効くと考えられる。ファミリーツリーの「毎月の農家レポート」(2章)も同じ発想。
- 収穫期・発送時期の明示(旬カレンダー)は、複数の好事例で共通する信頼要素。

### Gaps
- 生産者の顔写真、配色、タイポグラフィ、コピーのトーン、モバイルファーストのレイアウトと転換率の関係を示す公開データ・ケーススタディは見つからなかった。
- 農産物定期便の継続率・解約率の公開データは見つからなかった。
- 制作会社のまとめ記事は宣伝目的を含むため、「成功事例」の売上効果は検証されていない。

## 5. 法的要件(特商法表記・最終確認画面・食品表示・プライバシーポリシー)

### Takeaway
個人事業主でも継続的にネット販売すれば特定商取引法の通信販売規制の対象で、表示事項は15項目。2022年6月施行の改正で、定期・単発を問わず最終確認画面に6事項の表示が義務化された。定期便と会員権(前払い)を扱うなら、回数・総額・解約条件を最終確認画面に必ず出す必要がある。

### Cited Findings
- 通信販売の広告表示事項は法11条と施行規則23条を合わせて15項目。氏名(名称)・住所・電話番号、および申込みの撤回・解除(返品特約)は常に表示が必要な項目 — [issoh 解説(消費者庁逐条解説 2025年6月1日版に基づく)](https://www.issoh.co.jp/column/details/18188/)
- 個人であっても継続的に通信販売を行えば対象になる — [マネーフォワード(2025-08-28更新)](https://biz.moneyforward.com/tax_return/basic/79606/)
- 2022年6月1日施行の改正特商法で、事業者の定める様式による申込み(特定申込み、ネットの最終確認画面が該当)について、最終確認画面で契約内容が一目でわかる表示が義務化。定期購入だけでなく単発契約も対象 — [ネットショップ担当者フォーラム](https://netshop.impress.co.jp/node/9671) / [Web担当者Forum](https://webtan.impress.co.jp/e/2022/05/19/42764)
- 最終確認画面の表示事項は6つ:分量(数量・回数・期間)、価格(各回の代金と支払総額)、支払時期・方法、引渡し時期、申込期限、申込みの撤回・解除(解約の申込期限、解約料など)。解釈と具体例は消費者庁「通信販売の申込み段階における表示についてのガイドライン」に示されている — [ネットショップ担当者フォーラム](https://netshop.impress.co.jp/node/9671)
- 定期購入トラブルは改正法施行後も思ったほど減っていないと自治体教材が指摘 — [群馬県資料](https://www.pref.gunma.jp/uploaded/attachment/651749.pdf)
- 食品表示:消費者向けに販売される全ての食品に表示義務。生鮮の農産物は「名称」と「原産地」が基本で、原産地は原則都道府県名(市町村名や一般に知られた地名も可)。表示は容器包装のほか、近接した掲示・立て札・POPでも可 — [山形県 食品表示ハンドブック2026](https://www.pref.yamagata.jp/documents/1956/shokuhinhyouji_handbook_2026_part1.pdf) / [富山県 直売活動の手引き](https://www.pref.toyama.jp/documents/14086/chokubaikatsudou2603.pdf)
- 梅干しは「農産物漬物」として加工食品の表示ルールが適用され、生鮮品とは別扱い — [富山県 直売活動の手引き](https://www.pref.toyama.jp/documents/14086/chokubaikatsudou2603.pdf)

### Inferences
- 早和果樹園の「退会・休止は前月20日まで」(2章)のような解約期限は、最終確認画面の必須表示事項に当たる。年一括前払いの頒布会やオーナー制度は「回数・総額・途中解約不可」を申込画面に明記する設計が必要。
- BASE/STORES 等のカートを使えば特商法ページと最終確認画面の雛形は用意されるが、定期便・前払い会員の解約条件は自分で記入する必要があると考えられる(未検証)。

### Gaps
- 消費者庁の一次資料(特定商取引法ガイド、ガイドライン原文)は取得できず、二次解説に依拠している。
- 個人事業主が住所・電話番号の表示を省略できる条件(請求時に遅滞なく開示する旨の表示、プラットフォーム住所の利用など)は、解説記事の存在は確認できたが条件の本文を確認できなかった。
- 生鮮食品の返品特約の書き方、ネット販売時の食品表示の扱い(サイト上の表示義務の有無)は確認できなかった。
- 梅干し等の加工品販売に必要な営業許可(漬物製造業)・営業届出の要件は今回の検索で出典を得られなかった。加工品を扱う場合は保健所確認が必要。
- プライバシーポリシー(個人情報保護法上の利用目的の公表など)の要件は出典を得られなかった。
